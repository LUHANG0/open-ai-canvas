# OMP 项目协作规则

适用于在影策仓库使用 OMP 的开发工作。先阅读根目录 `AGENTS.md` 和受影响目录的约定；用户当前要求优先。本文件补充协作流程，不替代技术合同，也不是产品内 Agent 的提示词。

## 1. 分工与任务交接

- 用户选择“Codex 分析、OMP 实现、Codex 核查”时，按该分工执行。委派方负责需求、方案、范围和最终验收；OMP 负责实现、自查与证据。不暗中改成委派方自行写产品代码，需改变分工时先说明原因。
- 委派前写清：用户目标、真实入口、允许修改的文件/模块、保留项、验收项、明确不做的事项、可用环境、交付位置。不能只交付“高级、简洁、科技感”等形容词。
- 未明确分工时遵循当前任务，不自动启动其他代理。确需并行时限定独立文件范围，共享文件只有一个写入者；读取同一文件可以并行。
- 不把任务执行成功或 OMP 的完成报告当作最终验收。委派方必须查看改动和对应证据，并报告自己实际检查的范围。

## 2. 技能使用

- 根据根约定的任务表选择直接相关技能，实际读取正文并落实要求；不以“技能已安装/已列出”代替使用。
- 界面任务优先 `yingce-ui-experience`；画布交互补充 `yingce-canvas-editor`；React 改动按需使用 `vercel-react-best-practices`；故障用 `systematic-debugging`；完成前用 `verification-before-completion`。
- 用户提供参考要求还原时用 `reference-ui-recreation`；原创设计按需要补充设计技能。不要为一次局部排版任务加载全部技能，也不要把营销页视觉规则机械套进编辑器。
- 子任务交接写明必读技能及理由。发现不到技能时先查实际路径，不猜测已自动加载。子代理能看到技能目录并不证明它读过正文。

## 3. UI 任务先明确设计边界

- 先查看真实页面或由委派方提供当前截图，列出可观察问题；分清局部整理、视觉重做、参考复刻。局部整理默认保留原有风格与信息结构。
- 改前写一份简短布局说明：保留的视觉特点、信息优先级、控件分组、默认窗口下的尺寸关系、空态/有内容状态、窄屏和短屏行为。不要只列删减动作。
- “优化外观”不自动授权删除、隐藏或迁移重要功能。保留功能、入口、状态与反馈；必要调整须与用户目标一致并在方案中说明。用户已认可的调整无需重复确认。
- 未实现或研发中的功能应如实显示状态；不能仅因尚未实现就自行删除用户希望保留的入口，也不能伪装成已接通。
- 控件整理要核对原入口与新入口的对应关系，尤其模型、技能、连接器、权限、预算、引用、状态、发送/停止。区分操作、配置、状态，不把它们堆成同权重图标。
- 不把“减少装饰”当成设计完成。检查默认尺寸的整体比例、过大空白、文字对比、重复入口、按钮对齐与输入区是否像独立拼接件。不得仅用放大窗口截图掩盖默认尺寸问题。
- 沿用用户已授权的方向推进；需要改变整体风格或功能范围时，先说明具体变化。不要以此为理由对每次样式修改反复索要许可。

## 4. 可回退与改动保护

- 修改前检查未提交工作。用户要求保留原版时，保存本次范围内原文件、存在/缺失状态、差异与校验值，并明确“最初版”具体基线；不能假定 HEAD 就是用户所指版本。
- 恢复点放在 `.local/` 的本次目录，备份约定文件使用非 `AGENTS.md` 文件名。版本间分别留档，不覆盖最初版。
- 回退只恢复本次范围，并核对其后新增改动；不得整仓 reset、覆盖用户内容、数据库或其他任务文件。新增文件也要记录回退时如何处理。
- 提交、推送、部署各自遵循当前授权；“做一版看看”不表示允许提交或上线。

## 5. 实现与验收

- 保留真实事件处理和业务合同，不能为排版改写审批、计费、任务执行、保存或账号隔离逻辑；确有必要时扩大说明与验证范围。
- OMP 自查包含相关测试、类型检查及差异检查。选择最小充分验证，避免无意义重复；明确失败、跳过和未执行项。
- 临时验收副本与缓存遵循根 `AGENTS.md` 的“本地磁盘与任务收尾”。交接时列出本任务临时资源；完成后清理可重建副本，保留补丁、必要备份和验证记录，不把完整候选目录长期交给委派方堆积。
- UI 验收必须回到真实路由：默认尺寸、窄屏、短屏、必要主题、滚动、焦点、弹层、关键按钮；交互改动还要验证相应操作。截图和实际行为都要检查，构建/测试通过不能代替视觉验收。
- OMP 没有浏览器能力时，交付实现候选与待验清单，由委派方做浏览器检查；不得宣称真实页面已验收。
- 委派方发现视觉或行为问题时，将截图、具体位置、预期和实际差异反馈给 OMP 迭代。不要把明显不协调的候选直接作为完成版交付。
- 最终报告区分：实现了什么、OMP 验证了什么、委派方验证了什么、仍未验证什么。主观审美由用户判断，不能宣称用户认可。
