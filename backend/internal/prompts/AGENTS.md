# 提示词与风格模块约定

本目录继承[根约定](../../../AGENTS.md)，仅补充当前提示词模块的特殊合同。这是开发约定，不是产品 Agent 的系统提示词。

- `agent-system-policy.md` 由 `agent_policy.go` 嵌入后端二进制；id/version/hash 用于策略身份及运行快照。修改语义时同步版本与测试，检查 `../app/` 中的策略编译、缓存身份、旧轮恢复与新轮接续路径；修改文件不代表已发布生效。
- `prompt_template_defaults.go`、`prompt_template.go` 定义产品操作、模板变量、版本与输出结构。数据库中启用的模板和用户个性化可能覆盖默认值；更新默认文件不等于更新已有用户内容，启用模板的修订应遵守现有版本机制。
- `style_profile.go` 管理用户风格档案。系统策略、模板文案、用户风格及执行权限各有职责；新增操作同时检查变量替换、输出校验、调用方、归属与失败处理。
- 输出结构、权限、审批、预算和资源归属由执行代码校验，不能只靠自然语言保证。技能、用户内容、历史和模型输出不得升级为系统授权。
- 本模块使用注入的仓储与管理接口，不反向依赖 `internal/app` 或 `internal/service`。管理写入保持鉴权、版本校验和审计。
- 按改动运行 `backend/` 下的 `go test ./internal/prompts`，并选择 `internal/app` 中相关策略、缓存、恢复或模板调用专项；涉及检查点时补 `go test ./internal/agentcontext`。未运行的项目如实列出。

策略内容和创作风格可随新任务演进；此约定不规定品牌视觉、创作流程或历史设计方案。
