# 用户数据同步边界

本页用于判断一个前端状态应该上云、只做本地缓存，还是必须留在当前设备。业务内容不能仅因写入 IndexedDB 或 `localStorage` 就显示“已同步”；只有账号级接口成功写入后，前端才能显示云端成功。

## 判断新增状态应该保存在哪里

按下面顺序判断：

1. 用户换浏览器后仍应看到，或该状态参与任务恢复、项目交付与多人设备连续创作：服务端是主数据，本地只做离线缓存。
2. 状态包含 API Key、自定义请求头、本机路径或尚未提交的私密草稿：默认只留设备，除非先完成字段拆分、加密和产品授权。
3. 状态可由服务端资源或业务数据重新生成，例如 Blob、视频封面和缩略图：只做可淘汰缓存。
4. 状态只影响布局、滚动、焦点、最近使用或性能模式：保持设备本地，不进入账号快照。

| 入口或数据 | 当前权威来源 | 本地用途 | 结论 |
| --- | --- | --- | --- |
| 创作页对话、消息、附件引用、任务关联和结果引用 | `creation_conversations` | IndexedDB 离线读取和待上传队列 | 已改为账号级增量同步 |
| 自由画布项目和节点 | `canvas_projects` | Zustand/IndexedDB 缓存 | 已有账号级同步 |
| 素材、资源、短剧项目、章节、镜头、工作流和任务 | 各自服务端领域表 | 查询缓存和恢复状态 | 保持服务端主数据 |
| 绘图编辑文档 | IndexedDB `drawing_documents` | 当前也是唯一副本 | 待第二阶段改造，不能继续作为长期唯一副本 |
| 绘图预览、生成渲染、资源 Blob、视频封面 | 可从编辑文档或资源重新生成 | IndexedDB 缓存 | 不独立上云 |
| 项目编辑器未提交草稿 | IndexedDB | 崩溃恢复 | 保持设备私密；提交后由领域接口持久化 |
| 模型渠道配置 | 设备配置与服务端渠道配置并存 | 本机运行和选择 | 不允许整体上传；先分离模型偏好与密钥/请求头 |
| Canvas Agent 本机事件和诊断日志 | 内存或设备存储 | 本机执行与排障 | 默认不上传，避免泄露路径和诊断内容 |
| 主题、面板尺寸、滚动、焦点、最近/收藏样式、性能模式 | `localStorage` / `sessionStorage` | UI 偏好 | 保持设备本地 |

## 恢复创作页对话

创作页现在使用每条对话独立的服务端版本号。首次登录会读取旧的本地对话并迁移；日常编辑先写本地快照，再以约 900ms 合并窗口上传。页面工具条明确显示“正在读取云端、等待同步、正在同步、已同步、同步失败或需要合并”。

并发设备写入返回 `409 Conflict` 时，客户端按稳定消息 ID 合并双方新增消息，并合并任务 ID、结果 URL 和消费效果键。重试替换过的消息写入 `deletedMessageIds`，删除标记优先于旧设备仍持有的消息，防止历史内容复活。删除整条对话使用服务端软删除墓碑；离线旧设备不能用过期版本重新创建它。

失败边界如下：

- 云端失败时保留本地副本和待上传 ID，并显示失败状态；不会把本地成功伪装成云端成功。
- 浏览器恢复在线后自动重试，用户也可以点击同步状态手动重试。
- 创作对话云端请求最长等待 10 秒；网络半断开时会退出云端读取并开放本地副本，不无限阻塞创作页。
- 先保存业务快照，再更新本地同步游标；进程中断最多导致重复上传，不应导致本地修改丢失。
- 单条对话上限为 2 MiB、2000 条活动消息和 4000 条消息删除记录；账号结构化存储与会话数量配额继续生效。

相关接口：

| 接口 | 用途 | 冲突规则 |
| --- | --- | --- |
| `GET /api/creation-conversations` | 读取当前账号未删除的全部创作对话和版本 | 不返回其他账号数据或软删除墓碑 |
| `PUT /api/creation-conversations/:id` | 新建或按 `expectedRevision` 更新一条对话 | 版本过期或命中删除墓碑返回 `409` |
| `DELETE /api/creation-conversations/:id?revision=...` | 按版本软删除一条对话 | 过期版本返回 `409`，重复删除幂等成功 |

## 完成绘图文档的下一阶段同步

绘图文档不能直接把现有 JSON 上传到结构化表：从图片创建绘图时，tldraw 或 Excalidraw 快照可能包含 Data URL。直接同步会绕过资源存储、把大媒体计入错误配额，并留下跨设备不可读取的引用。

下一阶段按以下路径实施：

1. 保存前扫描绘图快照，将内嵌图片上传为当前用户的 `resources`，再把快照改写为稳定资源 ID 或存储键。
2. 增加用户和画布项目归属校验的绘图文档接口，结构化文档使用独立乐观版本；预览和渲染 Blob 仍只做本地缓存。
3. 首次打开旧文档时执行可恢复迁移；任何媒体上传或文档写入失败都保留本地副本并显示未同步，不更新云端成功标记。
4. 项目永久删除时在同一服务端事务中删除绘图文档；普通节点删除继续保留文档，以支持画布撤销。
5. 用含图片的 tldraw/Excalidraw 文档完成双设备读取、并发编辑、项目删除和配额测试后，才将该入口标记为云端主数据。

## 验收新的同步入口

每个新增同步入口至少覆盖：账号隔离、首次迁移、离线编辑、恢复在线、两个页面并发写入、删除与旧设备恢复、配额失败、服务端 `5xx`、本地存储失败以及刷新后的状态提示。若某种内容无法安全合并，应返回明确冲突并要求重新读取，不能使用“最后写入者”静默覆盖。
