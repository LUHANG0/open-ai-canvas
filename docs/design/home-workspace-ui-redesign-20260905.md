# 登录后首页工作台重构记录

## 目标

- 将 `/home` 从数据仪表盘改为“用户下一步创作入口”，让 1366×768 首屏同时出现主创作动作与可继续内容。
- 区分有活跃短剧项目、无短剧项目但已有画布/素材/任务、真正空账号三种状态。
- 使用轻电影感、任务优先、真实作品做视觉主体的首页语言，保持明暗主题、键盘与移动端可用。

## 边界

- 仅修改首页私有页面、样式、helper、测试与本记录。
- 不修改后端、API 合同、路由、Store、全局主题 Token、共享工作台壳层或公开官网。
- 不增加逐项目请求；项目主图复用 `coverResourceId`，其次复用画风图、任务预览与本地素材封面。
- “新建自由画布”继续调用既有 `createCanvasProjectWithRemoteSync`，保留本地创建与云同步降级语义。

## 关键决策

1. 项目请求不再控制整页渲染。项目、任务、本地画布/素材拥有独立 loading/error/degraded 状态。
2. 只有相关数据源已结束读取且均为空时，才显示真正空账号文案；项目失败或任务加载中不会误判为空账号。
3. Hero 只保留一个品牌紫主操作。有项目时为“继续制作”，返回用户为“继续创作”，真正空账号为“立即创作”。
4. 最近创作与任务状态紧跟 Hero；KPI 和图表后移。没有数据时不渲染大面积空图表。
5. 任务色只用于 queued/running；项目进度与普通选中不使用 AI 青。
6. 活跃度图的任务口径仍为最近 300 条；画布只按当前 `updatedAt` 统计，页面提供文字数据与口径说明。
