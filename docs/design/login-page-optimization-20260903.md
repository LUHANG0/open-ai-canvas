# 登录页体验优化记录（2026-09-03）

## 目标与边界

- 保留后台“品牌与外观”的动态文案、主题色和媒体资源投影，不写死站点身份。
- 优化桌面与移动端登录页的视觉层级、表单聚焦和状态反馈。
- 不修改账号、品牌配置、注册策略或现有业务数据。

## 完成内容

- 桌面品牌区增加叙事引导、细微纹理、创作能力标签和更清晰的标题比例，减少大面积无信息暗区。
- 登录面板重新平衡宽度、间距、主题光晕、表单控件和按钮状态。
- 移动端形成独立品牌头图与可滚动表单区，保持小屏可读性。
- 用户名自动聚焦并在提交前去除首尾空格；缺少用户名或密码时禁用提交。
- 登录失败同时提供表单内 `role=alert` 反馈，输入字段关联错误描述并设置 `aria-invalid`。
- 访客初始化不再请求受身份保护的模型目录，未登录打开登录页时控制台保持无错误、无警告。

## 验收结果

- `bun test`：前端全量测试通过。
- `bun run build`：TypeScript、Vite 生产构建和全部体积预算通过。
- 关联持久化回归：`user-scoped-generation-persistence.test.ts` 45 项通过。
- 登录页专项及品牌回归：11 项通过。
- 浏览器实测：桌面与 `390 × 844` 窄屏布局正常；未登录访问控制台 `errors=[]`、`warnings=[]`。
- 本地服务：前端 `8888`、后端 `8080`，健康检查返回 ready。
