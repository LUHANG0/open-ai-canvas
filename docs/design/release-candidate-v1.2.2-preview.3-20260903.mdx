## 生产发布顺序

1. 以候选提交构建或发布固定版本镜像，不使用 `latest`。
2. 对生产 PostgreSQL 执行 custom-format dump，并备份 Backend 数据目录；校验备份可读与 SHA-256。
3. 保持 PostgreSQL、Redis 运行，停止 Web/Backend，并等待 Backend drain。
4. 使用候选 Backend 镜像独立执行 `migrate-schema up`。
5. 启动 Backend，等待 `/api/health/ready` 连续稳定并确认 schema 6。
6. 启动 Web，验证首页、登录、品牌公开接口、创作对话云同步和资源读取。
7. 保留旧镜像标识、旧 Compose 和本次备份，完成观察窗口后再标记发布成功。
