## 已复现的基线问题

1. 导演台和时间线直接读取旧 `canvasThemes`，未消费正式画布的品牌 Theme Provider；导演台常暗色序列器/悬浮控件留在 globals。
2. 390px 手机导演台左栏占 180px，视口仅 210px；时间线工具栏 `overflow:hidden` 裁掉保存与导出，预览的字幕区被挤成窄列。
3. 时间线按 96px/秒绘制，192px 点击实际定位 960ms，而预期为 2000ms。标尺按整条最小 960px 宽度比例映射时长，与片段使用的比例不同。

本轮改造前实际运行 `bun run test:director:e2e`：58/58 通过；包含确定性场景、模型失败/重试、视口恢复、保存失败与关闭保护。这是 DEV 专项基线，不能替代正式入口验收。
