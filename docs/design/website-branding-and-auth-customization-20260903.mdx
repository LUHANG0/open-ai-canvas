# 网站品牌与登录页自定义化

## 交付状态

本轮采用“服务端单一配置源 + 前端运行时品牌 Provider + 管理后台编辑器”的方案。品牌名称、主题主色、Logo、浏览器图标、登录页背景和登录文案由管理员统一维护；登录、注册、工作台侧栏、首页、创作页、共享画布与注册验证码邮件读取同一份配置。

实现不新增数据库表或结构迁移。配置写入既有 `system_settings` 表的 `platform_branding` 键，资源沿用既有 `resources` 存储，管理动作写入 `admin_audit_events`。

## 管理入口与生效规则

入口：`/admin/settings/branding`。

- 文案与主题色在点击“保存修改”后整体生效。
- 登录页背景链接、媒体类型和视频海报链接在点击“保存修改”后生效；外链优先于已上传素材，清空后自动回到上传素材。
- Logo、favicon、登录页背景和视频海报上传后立即生效。
- 上传新的登录背景或海报时会清除对应外链配置，使刚上传的本站素材立即成为当前来源。
- 页面带修订号并使用 Compare-And-Swap 保存；另一标签页先保存时，旧页面会收到冲突提示，不会静默覆盖。
- “恢复默认”会恢复影策默认文案、颜色和资源引用，同时保留历史上传资源，便于人工恢复。
- 登录页配置请求失败时使用浏览器上次成功缓存；没有缓存时使用内置默认品牌，品牌服务异常不会阻断登录。

## 沉浸式视频登录页与单一入口

登录与注册共用的视觉入口最终使用 Refero 的 Origin Financial“午夜画廊”视觉语言，收敛为“全屏氛围视频 + 中央编辑感标题 + 白色主按钮 + 渐显暗色认证浮层”。首屏顶部只显示品牌标志和登录操作，中央显示可配置标题、说明和“进入影策”按钮，不提供产品、作品、关于等入口。点击后首屏淡出，视频平滑放大、压暗并虚化，居中认证面板再渐显出来。

- 视觉使用近黑画布、轻字重中文衬线标题、灰色正文、8px 控件圆角与白底黑字唯一主操作；删除旧版浅色卡片、胶囊按钮、双栏和装饰性渐变。
- 认证面板只显示品牌标志、当前登录或注册标题、真实表单和底部账号切换；面板为近黑平面，右上角可返回视频首屏。
- 背景视频在桌面和移动端均静音、循环、全屏裁切播放；系统要求减少动态效果或视频不可用时继续使用海报、图片或深色品牌渐变。
- 用户名与密码拆为两个独立输入框，重新定义标签、间距、圆角、边框、聚焦和浏览器自动填充状态；初次进入不强制聚焦，避免账号输入框出现突兀高亮。
- 认证区只使用中文提示；登录、注册、首管理员、关闭注册、邮件验证码及 Linux.do 的业务分支保持不变。
- 视频首屏显示期间会静默预载登录和注册模块，点击进入时还会等待同一预载任务完成，因此首次打开和后续切换都不会出现全屏加载占位；认证模块仍保持异步分包。
- 管理后台不再提供模拟预览，编辑页顶部直接提供“查看登录页”入口。

### 认证前端职责拆分（2026-09-04）

认证页不再由一个组件同时管理媒体、品牌内容、账号设置、路由预载、主题和表单。当前边界为：`auth-scene.tsx` 只协调视频首屏与认证浮层状态，`auth-media.tsx` 管理视频/图片/海报降级，`auth-entry.tsx` 管理首屏内容，`auth-panel.tsx` 管理浮层与登录/注册切换，`auth-settings-provider.tsx` 对 `/api/auth/settings` 做页面生命周期内的缓存和单请求合并，`auth-route-loader.ts` 负责两个小表单的后台异步分包与模块缓存，`auth-fields.tsx` 复用字段和第三方登录图标。场景样式与表单样式也分别收口到 `auth-scene.css` 和 `auth-form.css`。

路由层已移除登录、注册各自的 `React.lazy`、`Suspense` 和 `FullScreenLoader`，因此点击进入或在登录/注册之间切换时不会再进入工作台加载画面。两个表单仍在视频首屏挂载后静默预取，避免增加启动壳体积；生产构建验证启动壳 JS 为 `591.8 KiB gzip / 610.4 KiB` 预算。背景媒体挂在场景根部，不随入口、表单或路由切换卸载。

管理入口同步重做为亮色双区工作台：左侧固定显示品牌标志、名称、保存状态、主题色和“品牌资料、标志与颜色、登录页面、浏览器显示”四个纵向分区；右侧每次只显示一张编辑工作表，底部固定保存与恢复操作。英文名称、眉题和实时标记等高级字段只从编辑界面隐藏，服务端既有值仍会随完整配置保留，不会因为本次保存被清空；上传、外链、恢复默认、修订冲突和审计协议均未改变。

当前启用“单一公开入口”：`/`、`/product`、`/showcase` 和 `/about` 均重定向到 `/login`，登录页不再出现产品、作品、关于或返回首页入口；管理后台“官网内容”菜单暂时隐藏，旧管理地址重定向到品牌中心。公开官网组件、配置、草稿、发布数据和接口均未删除，后续可以通过恢复路由重新开放。对应代码回滚点：`be0f75d`。

本次仅调整展示层和默认文案，没有修改账号、Cookie、用户数据、注册策略或品牌配置存储结构。已有管理员自定义文案继续优先于新的内置默认值。

最终重做没有新增、删除或改名接口：品牌仍为 7 个接口，认证仍为 8 个主要接口和 1 个兼容回调。

## 配置范围

| 分组     | 字段或资源                                                           | 当前消费入口                                                          |
| -------- | -------------------------------------------------------------------- | --------------------------------------------------------------------- |
| 品牌身份 | 展示名、简称、工作台名称、标语、描述；英文名作为兼容字段保留         | 登录、侧栏、顶栏、首页、创作页、共享画布、注册邮件                    |
| 主题     | `#RRGGBB` 主色                                                       | 用户端 Ant Design 组件和品牌 CSS 色阶；管理后台继续使用稳定的后台主题 |
| 登录页   | 页眉、标题、描述、状态文案、HTTPS 背景 URL、媒体类型、HTTPS 海报 URL | 登录与注册共用场景                                                    |
| 浏览器   | 页面标题、Meta Description                                           | 全站运行时 `<title>` 与描述                                           |
| 品牌资源 | Logo、favicon、登录背景、视频海报                                    | 全站品牌标记、浏览器图标、登录页视觉区域                              |

技术标识不参与品牌替换，例如数据库键、IndexedDB 名称、剪贴板格式和 `infinite-canvas` 包名。这些字段属于兼容性协议，改名会导致旧数据或集成失效。

## 接口

| 方法     | 路径                                        | 权限   | 说明                                              |
| -------- | ------------------------------------------- | ------ | ------------------------------------------------- |
| `GET`    | `/api/public/branding`                      | 公开   | 返回安全的品牌文案、主题和资源 URL；支持 ETag     |
| `GET`    | `/api/public/branding/assets/:slot`         | 公开   | 只读取当前激活的品牌资源，支持 Range 与不可变缓存 |
| `GET`    | `/api/admin/settings/branding`              | 管理员 | 返回配置、修订号和资源引用                        |
| `PATCH`  | `/api/admin/settings/branding`              | 管理员 | 按预期修订号保存文案、主题和外链资源配置          |
| `POST`   | `/api/admin/settings/branding/assets/:slot` | 管理员 | 上传并激活指定资源                                |
| `DELETE` | `/api/admin/settings/branding/assets/:slot` | 管理员 | 清除指定资源引用                                  |
| `POST`   | `/api/admin/settings/branding/reset`        | 管理员 | 恢复内置默认配置                                  |

资源位置为 `logo`、`favicon`、`auth-hero` 和 `auth-hero-poster`。服务端按文件魔数识别 PNG、JPEG、WebP、GIF、MP4 和 WebM，不信任文件名或请求 MIME；Logo 和 favicon 不接受视频。大小上限分别为 2 MiB、512 KiB、40 MiB 和 8 MiB。SVG 暂不开放上传，避免主动内容进入公开资源端点。

外链模式只接受完整的 `https://` 地址，长度上限为 2048 个字符，拒绝 `http:`、`data:`、`javascript:` 和包含账号密码的 URL。后端不会主动抓取外链，因此不会产生服务端请求伪造面；资源由访客浏览器直接读取，CDN 的可用性、跨域策略和链接有效期由素材提供方决定。对稳定性要求高的品牌仍建议使用本站上传模式。

## 回滚与恢复

优先使用配置回滚，不需要回退数据库结构：

1. 进入 `/admin/settings/branding`，点击“恢复默认”。这会创建新的修订和审计记录，不会删除旧资源。
2. 若只需撤销单个媒体资源，使用对应资源卡片的“移除”；其他品牌配置保持不变。
3. 若外链异常，清空背景或海报 URL 并保存，即可切回仍被保留的本站上传素材。
4. 若需恢复某次历史内容，在管理审计记录中查找 `branding.update`、`branding.asset.upload`、`branding.asset.clear` 或 `branding.reset`。审计元数据包含变更前后的配置和资源 ID，可据此重新填写或重新激活资源。
5. 若品牌接口暂时不可用，前端会自动使用最后成功缓存或内置默认值；先恢复后端服务，不必清理用户浏览器数据。
6. 若必须做代码级回滚，只回退“变更记录”列出的品牌相关文件和路由注册。不要回退同一工作区中独立完成的创作对话云同步、媒体存储或其他未提交变更。

本次认证边界拆分与无加载切换位于独立提交，可执行 `git revert 443dd56` 恢复拆分前代码；午夜画廊视觉回滚点为 `c22472f`，上一版全屏视频重构点为 `cee212a`，均衡双栏回滚点为 `52775b1`，单一公开入口回滚点为 `be0f75d`。这些代码回滚都不会改写 `platform_branding`、官网草稿/发布内容、资源引用、用户账号或其他业务数据。

历史资源为可回滚性而保留，会继续占用资源存储和上传配额。确认不再需要后，可在资源管理中清理未被当前品牌配置引用的文件；当前激活资源会被服务端拒绝删除。
