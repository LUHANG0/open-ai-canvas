## 实施结果

- 四页专属规则迁到 `components/admin-configuration.css`，公共后台只保留公共和其他模块的规则；沿用品牌表面、选中、状态与焦点变量。手机字段单列，保存区可滚动到达，读取状态复用 BrandLoader。没有另建主题、增加全局控件补丁或升级依赖。
- 功能开放继续即时保存，失败恢复上次确认状态；刷新及读取失败时禁止旧配置写入，连续点击有即时提交锁。积分与模型目录关闭确认保持原语义。
- 注册即时开关与 OAuth 草稿独立。注册保存返回不再回填 OAuth，失败就地提示；OAuth、SMTP、存储先校验再取完整 Form 草稿，避免关闭主开关后未挂载字段漏入保存请求。原密钥留空保留、厂商隔离及服务端加密合同不变。
- 本地存储地址改为直接绑定 Form.Item 的输入框，「使用当前地址」与手动输入均可保存回读。连接测试、保存、撤销、刷新、字段修改互斥；离开后迟到结果不污染新页面。S3 明确提示关键配置必须先测试通过，再保存启用，保留后端检测摘要约束。
- 四页私有确认组件默认聚焦「继续编辑/取消」，处理首尾 Tab 循环；复现的末尾 Tab 焦点离开确认框已修复，无公共 Modal 样式或全局焦点监听修改。
- 普通用户验收发现 `RequireFeature` 模块级一次性读取标记使重新挂载停在等待状态。与 D2 协调后仅删除该标记，按 feature 生命周期重新读取并保留取消隔离。用户 scope、Store、服务端接口和画布代码不变。
