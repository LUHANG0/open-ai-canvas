### 三条关键操作链

1. **Agent 展开→主工具栏右侧避让→主栏左移→与固定左侧视图/素材栏交叠**：E-01 → F-01 → 统一底部空间分配。

3. **全选→所有选中项跳过视口裁剪→屏幕外节点挂载→封面/特效工作增加**：E-08/E-09 → F-08/F-09 → 区分逻辑选区、可见渲染和媒体任务优先级；耗时须以基准测试确认。

## 5. 统一交互方案

### 5.1 操作规则

- 点击素材主体：选中；在既有需要打开创作面板的入口保持原逻辑。拖动素材主体：移动，不同时触发播放、预览、生成。
- 视频/音频：显式播放按钮一次点击完成“加载并播放”；加载时有状态，失败能重试；播放中点击画面暂停，拖动不暂停/切换播放。
- 文本：非编辑状态可拖动；进入编辑后选字/滚动归文本编辑器，退出编辑再移动。
- 重命名：Enter 或点击外部提交一次，Esc 撤回；输入法组合未结束时不提交；空名称保留原值并提示。
- 同一层级只出现一个主要浮层；子菜单可以叠加，Esc 先退子菜单再退主面板，焦点回到触发按钮。
- 普通单项编辑支持撤销；批量导入、布局、复制、连线和 Agent 写回按事务分组。会产生外部副作用的动作不假装能完全撤销。
- “不可用”应显示原因，而不是点击后无反应；已有模型/权限判断保持不变。

### 5.2 布局与动效

沿用 [PC UI 设计系统](../ui-design-system.md)，不另起一套与 Admin 不协调的视觉规范。

| 部分 | 方案 |
| --- | --- |
| 底部 | 一个布局容器统筹视图区、素材区、主工具栏和模式区；Agent 打开时按剩余空间分配，不允许互相盖住 |
| 节点操作热区 | 常用屏幕控件沿用 30/36px 档；节点关键操作至少 24px，播放优先 30px；小节点放不下时以聚焦预览代替重叠热区 |
| 工具栏 | 悬浮只改变图标/背景，避免按钮宽度随指针改变；危险项单独分组；低频动作收进更多 |
| 素材悬浮 | 仅放大视觉预览，不改变节点坐标/布局；拖动、多选、连接、性能模式下不启用放大 |
| 设置面板 | 固定标题、独立内容滚动、固定说明区；图片/视频/音频共用定位壳，避免超出可用视口 |
| 字体和间距 | 控件 13px、正文 14px；4px 基础间距；长标题省略并提供完整提示，不挤压操作按钮 |
| 时长 | 使用既有即时 120ms、普通 180ms、抽屉 240ms token；一层元素负责一次进出动画，不叠加两套位移 |
| 减少动画 | 同时作用于 CSS 和 JS motion；保留必要状态文字，取消缩放、指针光效及非必要位移 |
| 外观 | 保留 6 种底纹与深浅色；低倍率降低密度/对比度，避免底纹比素材更抢眼 |

### 5.3 性能策略

1. 逻辑选区、屏幕渲染和媒体加载分别管理；全选不意味着渲染所有屏外媒体。
2. 画质优先只提高封面/图片预览质量，不自动加载全部视频，更不改变生成模型的输出质量。
3. 性能优先使用单张可识别封面、较小预览图、轻量边框；不能以黑块取代视频素材。
4. 新选中/请求播放的媒体优先于后台封面；队列支持取消/降优先级，同源多档请求合并，保留已有好封面。
5. Agent 保留会话和草稿，隐藏时暂停非必要的视觉计算；不得误停正在进行的生成或任务结果接收。
6. 首次打开慢与重复打开卡分别测；先记录长任务、渲染数量和内存，再决定进一步拆分/虚拟化范围。

## 7. 集中验收方案

使用独立测试画布/账号或浏览器级隔离数据；不在真实作品上执行破坏性测试，不通过改数据库制造测试场景。

| 维度 | 覆盖范围 | 通过标准 |
| --- | --- | --- |
| 规模 | 空画布、10 节点、50 个混合媒体节点、200 节点压力场景 | 选中、全选、缩放、面板不失去响应；压力场景可降级但不黑屏 |
| 视口 | 1024×768、1280×720、1440×900、1920×1080；Agent 最小/常用/最大宽度 | 所有可见按钮可点击，浮层不越界，输入和底部栏不相互覆盖 |
| 缩放 | 5%、14%、25%、50%、100%、200% | 播放/端口可发现；低倍率操作不误拖；适应内容/选择正确 |
| 节点状态 | 空、成功、生成中、失败、锁定、单选、多选、容器折叠 | 显隐、禁用原因与实际处理一致 |
| 鼠标 | 点击、双击、拖动、拖出窗口、释放、取消、滚轮、右键、多选 | 一次手势一个动作，无粘住拖动/误播放/事件穿透 |
| 键盘 | 输入法、Enter、Esc、Tab、方向键、删除、撤销、复制粘贴、缩放、搜索 | 输入与画布快捷键互不抢夺，菜单说明与实现一致 |
| 历史 | 修改后立即撤销、连续撤销重做、批量操作、绘图删除恢复 | 数据和资源均恢复，不只恢复节点壳；面板指向正确 |
| 素材进入 | 文件选择、拖入、粘贴、素材库、提帧、切图、时间线回写、Agent 回写 | 保持原比例，批次紧凑、整体避让，失败项明确 |
| 媒体 | 首次/缓存播放、暂停、拖动、切换节点、失效地址、封面失败 | 单击播放、拖动不播；保持可识别封面及重试入口 |
| 生成 | 模型/参数/引用→提交→等待→成功/失败→回填→保存→重开 | 不重复提交、不丢结果；需真实付费调用时另行确认预算 |
| 保存 | 本地成功/云同步失败、刷新、快速跳转、离开页面 | 状态准确，能重试；不将本地成功当作云端成功 |
| Agent | 冷/热打开、网站/本机、历史、草稿、发送中切换、批次写回/撤销 | 位置稳定、状态不丢；隐藏不能误停任务 |
| 分享 | 创建、剪贴板失败、复制、轮换、撤销、访客页 | 部分成功说明准确，旧链接生命周期遵循现有 API |
| 浏览器 | Chrome/Edge、Safari、Firefox 的 PC 当前支持范围 | 播放、下载、剪贴板、拖放均有成功或可理解的降级提示 |

性能验收目标（须记录测试机器和浏览器，不能跨设备直接比较）：

- 热打开 Agent 到可操作的 p95 目标不超过 300ms，避免连续超过 100ms 的主线程长任务；首次模块/资源加载单独统计。
- 50 节点场景拖动目标接近 60fps；200 节点性能模式先以稳定可交互为准，暂定不低于 30fps，达不到则分析轨迹后调整实现而非假报通过。
- 重复开关面板、跨节点播放、切换媒体模式后，播放器、对象 URL、事件监听数量不得持续无界增长。
- 逻辑全选不导致屏外媒体 DOM 全量挂载；非播放视频使用封面，生成参数、计费和最终输出质量保持不变。
