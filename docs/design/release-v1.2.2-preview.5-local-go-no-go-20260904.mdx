# v1.2.2-preview.5 本地候选验收与 Go/No-Go

## 结论

**分层结论：本地 Go，可合并；线上 No-Go，不可发布。** 候选功能、数据库、镜像、恢复和浏览器验收均通过。原始 `main` 与候选分别执行 `bun run format:check` 都报告相同的 386 个文件不符合 Prettier，证明它们是既有基线问题；严格复现 `.github/workflows/quality.yml` 的 changed-files 逻辑后，只选中本次修改的 `registration-invite-drawer.tsx`，检查通过。因此这 386 个文件登记为非本次回归的 P3 技术债，不阻断 preview.5 的本地合并。

本记录只证明本地隔离环境中的候选行为。**仅本地通过，不代表 GitHub Actions、GHCR 或生产环境通过。** 本轮没有推送、远程 PR、Actions、远程标签、GHCR 发布、部署、生产数据访问或付费渠道调用。用户提供的线上已知阻断为 GHCR `permission_denied`；它不是本轮本地验证结果，未来申请上线前仍须单独解决并取得不可变 digest 证据。

## 数据库迁移与邀请制验收

最终 PostgreSQL 实例包含迁移 1–8，`registration_invites` 有主键和 8 个业务索引，共 9 个索引。外键策略复核如下：

- `created_by → users(id)`：`ON DELETE RESTRICT`。
- `used_by → users(id)`：`ON DELETE SET NULL`。

迁移在 SQLite 和 PostgreSQL 两套引擎上验证 fresh、跨版本升级和重复执行。SQLite 测试从固定共享内存 DSN 改成每测试独立临时文件，消除了重复运行时连接生命周期互相污染；V6→Schema 8 成为显式用例。PostgreSQL 额外覆盖 100 条历史邀请数据升级及 credits 回填。

真实候选栈完成以下邀请链路：

- 50、100、自定义 275 三类邀请分别注册成功，账户初始额度精确为 50,000,000、100,000,000、275,000,000 microcredits，并存在对应账本记录。
- 注册请求注入 `role=admin` 和超大额度字段后，新用户仍为普通 `user`，额度仍精确取邀请的 100 credits。
- 无效用户名导致注册事务失败时邀请不被消费；修正输入后同一邀请可成功注册。
- 同一 75-credit 邀请并发提交两次，仅一个用户创建成功，另一请求返回“邀请已使用”。
- invalid、expired、revoked、used 四种终态页面均在真实浏览器中确认。
- 正常复制显示“已复制”；强制 Clipboard API 与 `execCommand` 同时失败时显示“复制失败，请手动选中链接复制”。

## 合并建议与线上放行条件

本机建议合并 `release/v1.2.2-preview.5`；本轮按用户要求只给出建议，不实际合并。386 个 legacy 格式文件另列 P3 技术债，治理时应使用独立提交，避免与 preview.5 混入大范围无语义重排。

线上仍保持 No-Go，直到以下条件全部满足：

1. 获得远端操作批准后推送候选，确认最终合并 SHA 的 required GitHub Actions 全绿。
2. 解决 GHCR `permission_denied`，从最终 `main` 不可变 SHA 重新构建，并记录 version tag、SHA tag、OCI revision 与 RepoDigest 的一致关系；不得用 `latest` 代替。
3. 使用固定不可变 digest 在获批环境启动，再次核对 readiness、schema、邀请注册和备份恢复。

在候选 worktree 的 `web/` 中运行下列 Bash。主体与 `quality.yml` 的 “Check formatting” step 一致，只额外打印选中文件以便取证：

```bash
BASE_SHA=3e1ff98dac1ef35af8547b086ed6ccafb3be1561
GITHUB_SHA="$(git rev-parse release/v1.2.2-preview.5)"
changed_files=()
repo_prefix="$(git rev-parse --show-prefix)"
while IFS= read -r -d '' file; do
  case "$file" in
    *.css|*.html|*.json|*.js|*.jsx|*.md|*.mdx|*.mjs|*.cjs|*.ts|*.tsx|*.yaml|*.yml)
      base_path="${repo_prefix}${file}"
      if git cat-file -e "$BASE_SHA:$base_path" 2>/dev/null \
        && ! diff -q \
          <(git show "$BASE_SHA:$base_path") \
          <(git show "$BASE_SHA:$base_path" | bunx prettier --ignore-path /dev/null --stdin-filepath "$file") \
          >/dev/null; then
        echo "Skipping legacy unformatted file: $file"
        continue
      fi
      changed_files+=("$file")
      ;;
  esac
done < <(git diff --relative --name-only --diff-filter=ACMR -z "$BASE_SHA" "$GITHUB_SHA" -- .)
printf 'Selected: %s\n' "${changed_files[@]}"
bunx prettier --check "${changed_files[@]}"
```
