# PC 用户端页面清单

| 模块 | 路由 | 关键能力 | 视觉类型 |
| --- | --- | --- | --- |
| 认证 | `/login`、`/register` | 登录、注册、验证码、OAuth、`next` 回跳 | 全屏 |
| 公开分享 | `/share/canvas/:token` | 只读画布、有效/失效状态 | 全屏 |
| 首页 | `/home` | 统计、活动、最近项目、快捷入口 | 标准页 |
| 创作 | `/create` | 文本/图片/视频、素材、历史、重试、画布交接 | 沉浸式 |
| 任务 | `/tasks` | 筛选、列表/网格、轮询、详情、日志、恢复 | 标准页 |
| 素材 | `/assets` | 分类、上传、CRUD、ZIP、批量、预览 | 标准页 |
| 技能 | `/skills` | 列表、安装、编辑、同步、文件树 | 标准页 |
| 插件 | `/plugins`、`/plugins/eagle` | 启停、配置、文档、Eagle 文件与目录 | 标准页/子导航 |
| 积分 | `/wallet` | 余额、签到、兑换、流水、分页 | 标准页 |
| 设置 | `/settings?section=*` | 本机、渠道、模型、插件、偏好、存储、诊断 | 标准页/子导航 |
| 项目库 | `/projects` | 创建、导入、无限加载、搜索、归档 | 标准页 |
| 项目详情 | `/projects/:projectId/**` | 概览、章节、素材、画布、设置、六阶段工作流 | 标准页/沉浸式 |
| 画布库 | `/canvas` | 新建、查询模式、导入、批量删除、项目关联 | 标准页 |
| 画布编辑器 | `/canvas/:id` | 节点、生成、素材、时间线、绘图、导演、分享 | 独立工作台 |
| 内部原型 | `/test-voice-recording` | 录音、转写、原型发送 | 标准页 |
| 系统状态 | `*`、route error | 404、重试、返回 | 全屏 |

根路径 `/` 保持重定向 `/create`。`/dev/folders`、`/dev/director-repro` 仅作开发回归。`/admin/**` 不在本次实施范围。

## 不可变合同

- `RequireAuth` hydration 与完整 `pathname + search` 回跳。
- 五类功能开关及插件管理员绕过。
- Settings 的 `section` 查询参数。
- Canvas 的 `mode=new|recent|choose|handoff` 查询参数。
- 项目六阶段与所有深链接。
- 各页面现有客户端、服务端和无限分页语义。
- 所有 API 请求、轮询、幂等、上传、本地持久化和远端同步行为。
