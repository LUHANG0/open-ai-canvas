# 全局品牌加载动效

- 基线：`c8308be3`，主仓库干净并继承 `origin/main`。
- 实施分支：`feat/brand-loading-motion`。
- 设计：以品牌 Logo 与取景框为主体，四角逐格点亮；全页、页面内部、弹窗及按钮共享动效语言。
- 范围：首屏启动、会话恢复、路由等待、通用加载状态与 Ant Design 默认加载图标。保留实际进度、取消操作、权限和业务请求边界。
- 短暂路由等待延后显示，不设置最短等待时间；减少动画或应用内无动效偏好下显示静态图形。
- 本轮只更新本地代码与 `3012` 预览，不部署、不修改后端或生产数据。

动效以四角取景框为主体，1.8 秒循环，相邻四角错开 150ms 亮起；全页中心显示当前网站配置的 Logo，Logo 保持稳定，底部四段短线同步亮起。动画仅表示等待，不显示估算百分比或假成功状态。小尺寸控件沿用同一形状，并继承所在按钮文字颜色，保持主按钮对比度。

`BrandLoadingIndicator` 是无状态装饰组件，`BrandLoader` 负责文案组合；现有加载边界继续管理显示与关闭。首屏通过 `index.html` 引用同一份 `brand-loading.css`，React 下载期间即有可见反馈，挂载后自然接管。品牌配置就绪前使用不带名称的取景框，避免硬编码另一套品牌身份。

删除旧全屏骨架与单独转圈样式，保留页面数据骨架及既有加载边界：

- 首屏/会话恢复、共享画布：`FullScreenLoader`。
- 用户端与后台路由等待：`WorkspaceRouteLoader`，140ms 后显示；Suspense 完成即卸载，计时器在卸载时清理。
- 通用加载页与数据骨架：`WorkspaceState` 的 loading 分支和 `WorkspaceLoadingState`。
- 全局 Ant Design 默认 Spin、按钮：`AppProviders` 的 `ConfigProvider` 配置；显式自定义图标与已有真实进度条不受影响。
- 画布全页、内联面板及弹窗：复用上述组件和图标，关闭入口、最小高度、画布主题及手势隔离属性保留。

首个应用分块导入失败时，启动占位改为错误提示并显示重新加载按钮；禁用 JavaScript 时提供文字提示。首屏主题沿用工作台偏好，公开页固定深色；读取本地偏好失败时默认深色。

## 回滚

在干净工作区从 `main` 创建回滚分支，先撤开发预览，再撤共享组件：

```sh
git switch -c revert/brand-loading-motion main
git revert d0825386 930ae3af
```

保留本记录供追踪，按回滚后的实际状态更新待测试清单与设计文档。不能只删除新组件文件：HTML、默认 Spin、路由和画布加载区都依赖它。回滚不需要数据库迁移或恢复业务数据；验证后按原发布流程处理。
