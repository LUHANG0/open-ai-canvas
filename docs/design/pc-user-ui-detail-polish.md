# PC 用户端逐入口精修规范

## 1. 目标

本阶段建立在 Brand V2“光帧导演台”基础上，不重新更换视觉方向，而是把一级页面、二级入口、弹窗/抽屉、表单和完整交互状态打磨到可上线质量。

- PC 用户端验收范围：`>= 1024px`。
- `< 1024px` 只做保护回归，不改变现有移动端视觉和交互。
- 后端、Admin、数据库、API、接口返回、权限、业务规则、router、services、stores 与 `globals.css` 禁止修改。
- 保留所有现有事件、参数、请求、轮询、上传、生成、分页、跳转与计费逻辑。

## 3. 每个入口的验收维度

每个模块不能只验收默认截图，至少检查以下维度：

1. **层级**：页面标题、说明、主要命令、次要操作和危险操作清晰分层。
2. **密度**：首屏不出现无意义大空白；表格和卡片不拥挤、不截断关键业务值。
3. **状态**：默认、Hover、Active、Selected、Focus、Disabled、Loading、Empty、Error、Success。
4. **反馈**：上传、生成、保存、删除、启停、兑换等动作有清晰的进行中与结果反馈，但不改变业务实现。
5. **长内容**：长模型名、长提示词、长金额、长文件名与多标签均能安全截断或换行，并保留可读入口。
6. **滚动**：页面滚动、内部表格横滚、Drawer/Modal 滚动互不污染；1024px 不产生全局横向滚动。
7. **可访问性**：语义标题、按钮名称、`:focus-visible`、44px 关键触控目标、状态不只依赖颜色。
8. **主题**：亮/暗主题均可读；品牌紫只表示主动操作，AI 青只表示运行/生成。
9. **动效**：Hover 位移不超过 1px；`prefers-reduced-motion` 下停止循环和位移动效。
10. **隔离**：Admin palette、移动端基线以及所有业务/API 合同保持不变。

## 4. 文件 Owner

| Owner       | 独占范围                                                                               |
| ----------- | -------------------------------------------------------------------------------------- |
| Creative    | `pages/home/**`、`pages/create/**`、`pages/projects/**`、`pages/canvas/**`             |
| Content     | `pages/tasks/**`、`pages/assets/**`、`pages/wallet/**`                                 |
| Ecosystem   | `pages/skills/**`、`pages/plugins/**`、`pages/settings/**`、Auth/System/Voice 私有文件 |
| Integration | `components/ui/pc/**`、workspace shell、Foundation、测试、文档、最终集成               |

共享文件只能由 Integration 修改。各模块只能在页面私有 CSS 中追加 `@media (min-width: 1024px)` 规则，不能让精修样式泄漏到移动端。
