## 实际改动

### 创作页面

- 桌面与手机共用一个输入区，空会话按标题、输入区、灵感推荐排列；已有会话保持跟随输出的滚动行为。
- 输入、模型与参数控件、参考素材、推荐卡和结果区域沿用 A 批品牌语义；移除重复的旧桌面配色和全局浮层覆盖，恢复可见焦点环。
- 无法提交时展示当前原因；文本空完成、失败、主动停止与媒体未返回分别提供准确提示。文本助手名称读取当前品牌简称。
- 模型协议、提交准备、费用、上传引用、会话与画布回调保持既有合同。

### 任务中心

- 页面专属规则归回 `tasks-pc.css`，其中基础样式适用于所有视口；手机列表保留模型、画布、时间、积分与操作。
- 网格的详情、重试入口常驻显示；空状态区分没有记录和筛选无结果，加载失败与缓存提示覆盖手机。
- 列表、网格和详情共用状态显示：取消使用中性色，实际失败使用错误色，上游提交状态不确定使用警告色。分组明确显示“失败/取消”。
- 保留取消、内容审核禁重试、批量重试、分页与费用判断；详情日志不再使用独立的蓝色背景。

### 素材库

- 统一标题、容量、分类、卡片、批选、上传预览、素材档案与编辑表面；手机分类可滚动，窄屏卡片按单列呈现。
- 空库视觉复用现有品牌概念图并明确标注 AI 概念，不向用户素材库写入演示素材。
- 编辑表单的预览订阅保留未挂载字段值，解决首次打开已有素材时标题、标签预览显示为空的问题。
- 忙碌、错误、清除筛选和编辑反馈覆盖手机；上传、归档及删除引用检查保持既有处理。Eagle 与选择器仍共用的封面、分类、档案标题样式保留。

三个模块各自提交包含对应的 `globals.css` 样式迁移；没有新增全局 Ant Design 控件补丁、并行主题系统或后端接口。

## 回滚

提交顺序为记录 → 创作 → 任务 → 素材 → 旧测试 → 验收记录。回滚前先检查 `git status --short`，保留用户及其他任务的改动，在新的 `revert/*` 分支操作；不强制重置，也不回退数据库、上传文件或品牌配置。

整批代码按以下顺序撤回，保留本记录供追踪：

```sh
git switch -c revert/brand-core-flow main
git revert c2e956c5 63f4310f 80a982f8 23f656e3
```

上述顺序的反向补丁已在临时 index 预演，前端代码与 A 批基线 `48c054c2` 完全一致。正式回滚后在 `web/` 执行相应专项与生产构建，再合入 `main` 并沿既有流程发布。

单模块可定位到表中的实现提交执行 `git revert <提交>`。任务与素材都调整了页头按钮排除选择器，并共享一份回归测试；只撤回其中之一可能遇到上下文冲突，应保留另一模块仍需的选择器和断言。先验证后合入，不用覆盖整个共享文件解决冲突。

当前交付仅更新本地 `main` 与 `3012` 预览；未推送或部署。B 的其余页面、C 后台完整页面、D 画布与导演台等工作台继续分批处理，详见 [全站风格审计](brand-style-unification-audit-20260905.md)。
