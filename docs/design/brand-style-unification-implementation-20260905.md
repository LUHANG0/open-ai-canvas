## 回滚原则

每阶段独立提交。需要回滚时先检查 `git status --short`，保留其他任务和用户修改，再对本记录列出的实现提交按时间倒序执行 `git revert <提交>`。不使用 `reset --hard`，不还原用户数据目录，也不回退本批之前已完成的网站设置和登录修复。

开发预览由 Vite 读取当前工作树；回滚代码后确认页面重新加载。线上静态站需要重新构建并部署对应版本，开发预览更新不代表线上已发布。
