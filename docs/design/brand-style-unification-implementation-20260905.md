## 实施明细

A1（`4e1d8d6d`）删除桌面用户端和后台之间的重复色板，统一暗色页面 `#101115`、表面 `#191b22` / `#22252e`；主操作保留黑白，品牌色用于链接、焦点和选中态。后台继续保留表格密度。官网与认证路由固定深色，工作区仍读取用户明暗偏好；移除按视口选择主题的分支，布局断点保持原合同。

首轮 21 项主题、路由、官网及登录专项测试通过，含极亮/极暗自定义强调色的对比度检查。首次类型检查发现主题合并后重复声明，已移除重复项，后续类型检查通过。

A2 统一前后台外壳的留白与边框、导航选中态、完整 Logo、首页主操作与新用户品牌概念视觉。创作页继续复用当前布局，表面与文字接入共享变量；专有作品和用户预览保持原始内容。删除全局重复后台变量、侧栏规则及强制清除输入焦点的旧覆盖，后台表单聚焦实测为品牌边框与 2px 焦点环。后台浮层保持独立滚动与原有操作。

A3 使用存储事件按需读取新的品牌/官网配置，不进行定时轮询。配置保存会使较早发出的读取失效，避免旧响应覆盖新配置；官网保存直接采用服务端返回的 `publishedRevision` 与 `published`，公开缓存不包含后台草稿或管理员元数据。后端接口、CAS、授权、审计和数据库结构未修改。

## 回滚操作

先检查 `git status --short` 并保留其他任务和用户修改。完整撤回本批实现时按以下顺序逐个执行，遇到冲突先停止并核对后续改动：

```bash
git revert bcd04c7c
git revert 7aed7a67
git revert 4e1d8d6d
```

仅撤回跨标签页同步时，只撤回 `bcd04c7c`；撤回主题基础时必须先撤回依赖它的外壳阶段。记录文档可保留用于追溯。不使用 `reset --hard`，不还原用户数据目录，也不回退本批之前已完成的网站设置和登录修复。

开发预览由 Vite 读取当前工作树；回滚代码后确认页面重新加载。线上静态站需要重新构建并部署对应版本，开发预览更新不代表线上已发布。
