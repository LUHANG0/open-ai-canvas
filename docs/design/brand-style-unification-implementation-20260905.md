## 回滚原则

A1 删除桌面用户端和后台之间的重复色板，统一暗色页面 `#101115`、表面 `#191b22` / `#22252e`；主操作保留黑白，品牌色用于链接、焦点和选中态。后台继续保留表格密度。官网与认证路由固定深色，工作区仍读取用户明暗偏好；移除按视口选择主题的分支，布局断点保持原合同。

验证：21 项主题、路由、官网及登录专项测试通过，含极亮/极暗自定义强调色的对比度检查。首次类型检查发现主题合并后重复声明，已移除重复项；最终类型检查和浏览器结果在验收节补齐。

每阶段独立提交。需要回滚时先检查 `git status --short`，保留其他任务和用户修改，再对本记录列出的实现提交按时间倒序执行 `git revert <提交>`。不使用 `reset --hard`，不还原用户数据目录，也不回退本批之前已完成的网站设置和登录修复。
