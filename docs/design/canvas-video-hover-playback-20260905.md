# 画布视频悬停原声播放（2026-09-05）

鼠标在视频上停留 180ms 后播放原素材和原声，移开后暂停；再次进入继续播放。中央播放按钮与中央暂停提示已移除，底部播放、进度、音量和全屏控件保留。代码和测试提交为 `6dd19013`，修改前基线为 `9cf0a450`。

用户确认保留原来的工具栏：悬停不选择素材、不打开创作面板，点击素材仍按原规则展开面板。此前尝试的独立“创作”入口已撤回，本次没有修改工具栏或节点焦点路由。

## 播放与性能边界

- 鼠标悬停预览共用一个活动播放会话，切换视频会立即停止上一段；180ms 内划过会取消尚未开始的预览。
- 普通未选中视频保留静态封面，仅悬停目标临时加载播放器；离开后释放。唯一选中视频可以保留暂停的完整播放器，因此“一个活动播放会话”不等于始终只有一个已挂载播放器。
- 拖动、取消、素材替换、页面隐藏、窗口失焦及组件卸载会撤销播放意图。迟到的资源或播放结果不能重新出声。专用编辑器的硬禁播标记仍优先。
- 同一次节点挂载期间保存播放位置、用户调整的音量与静音状态；不修改原素材，不把播放进度写入画布数据。重新载入页面后使用默认原声音量。
- 手动暂停后，进度调整或缓冲完成不会恢复自动播放；点击画面或底部播放控件可继续。可聚焦的视频表面也提供 Enter / 空格入口。
- 浏览器可能拒绝没有用户交互的有声播放。失败时保留原声并提示“点击画面播放原声”，不自动静音。限制说明见 [MDN 自动播放指南](https://developer.mozilla.org/en-US/docs/Web/Media/Guides/Autoplay)。
