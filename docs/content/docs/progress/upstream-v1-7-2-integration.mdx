## 批量下载（2026-10-28 接入）

本批以 `eca8b388` 为基线参考 `bc839b56`，保留本地菜单、选择、预览、单文件命名和 OSS 下载访问合同。选择多个节点后，在节点或画布空白处右键可使用「下载 N 个资源」。文字、空节点、生成中、上传未完成及合成未完成的媒体不计入可下载数量；下载时使用同一筛选函数，按点击时的媒体引用快照执行。

- 同名文件在批次内增加序号，节点 ID 去重，保留节点顺序。
- 下载地址分窗口最多并发解析 3 个，逐个交给浏览器并保持间隔，不提前获取整个大选区的地址，也不读取媒体为 Blob 或打包 ZIP。
- 部分访问失败或浏览器交付抛错不阻断其他文件；提示启动数、失败数和跳过数。「已开始下载」表示已交给浏览器，不宣称物理文件已保存。
- 一个画布实例只保留一个活动批次；账号变化、会话重新初始化、切换画布或卸载时取消旧批次。签名迟到回调不能触发下载或发布旧账号结果；已经交给浏览器的下载不能撤回。
- 单文件下载继续复用同一地址解析和浏览器交付入口，补充签名返回后的账号检查与协议校验。
- 菜单新增项后，原固定高度估算在 390px 手机上出现底部裁切。用实际菜单高度及窗口尺寸定位，约束可用高度并保留内部滚动；回归用例先复现 891px 底边超出 844px 屏幕，再验证修复。

验证：48 项下载、菜单和媒体专项，139 项二改保护用例通过；前端类型、Lint、构建通过。真实 `/canvas/batch-download-fixture` 路由使用隔离账号、接口夹具和本地 PNG/MP4/WAV 文件，7 个混合节点准确显示 4 个可下载媒体；4 个实际浏览器下载文件逐字节匹配原件，同名图片不覆盖；拒绝其中一个下载访问后仍下载其余 3 个并显示失败数；第一文件启动后返回创作台，后续文件停止。手机菜单边界为 x=154、y=413、width=224、height=419，在 390×844 屏幕内。切号、A→B→A、等待签名时取消、重复点击与卸载由隔离生命周期用例验证。接口夹具未覆盖完整素材自动同步和真实 OSS/CDN，相关夹具告警不作为这些链路的验收证据；没有操作真实用户素材、数据库或付费任务。

## 真实素材补测与首次缓存保护（2026-10-28）

本地留存的 `HANGLU` 临时验收凭据与当前账号匹配，已通过正常登录完成已有素材验证，没有重置账号密码。现有资源全部为 `local`，因此此次真实文件验收覆盖平台本地存储，不代表 OSS/CDN 或真实音频下载已通过。图片单文件、图片与视频批量下载成功，下载文件 SHA-256 与存储原件一致；图片放大预览及 1280×720 视频播放正常。浏览器端临时注入一次访问失败后，其余文件继续下载并显示失败数；首个文件启动后返回创作台，后续交付停止。空媒体选区禁用下载；390×844 屏幕的实际菜单底边为 832px。

收尾核对发现一个早于批量下载改动的同步问题：空缓存首次接收带 `generationEffectKeys` 的云端画布，本地普通持久化因缺少本地祖先而移除标记，随后可能回写云端。隔离用例先复现标记从内存到本地保存后丢失；修复在缺少本地祖先时保留原项目，避免把空缓存当成标记未确认的证据。已有本地祖先时继续执行原有未确认生成保护。新增首次保存、重载回归后，98 项生成一致性、持久化丢失、版本合并和云端同步专项通过，类型检查通过。真实复核及字段恢复证据留在本次本地验收记录。

### 行为与边界

- 后端生成结果下载从固定 3 分钟改为单次最多 15 分钟，连续 90 秒没有收到字节时结束本次下载。仍服从父任务截止时间、取消和租约，不能保证所有配置的任务都有完整 15 分钟。停滞按可重试的媒体保存失败处理，沿用原 task/checkpoint 恢复，保留暂存预算、字节校验、失败文件清理、代理与脱敏日志。
- 前端仅把服务端确认的 failed/cancelled 归类为任务终态错误；网络断开、轮询超时、结果读取或保存确认失败保留为同步问题。创作页和画布提供「重新获取结果」，查询同一 taskId，不通过此入口重新提交付费生成。真正任务失败继续保留既有重试路径；不改变取消、提交不确定和本地图层拒绝的独立语义。
- 创作页恢复监听累积整批任务快照，逐项挂载结果但在整批收敛后才确认完成，避免历史合同中的完成态回退。已完成图片继续显示；其余任务仍运行时保留等待状态，已成功但结果不可读时保留恢复入口。文本结果不可读时保留已有流式正文。迟到结果不能替换新的任务绑定。
