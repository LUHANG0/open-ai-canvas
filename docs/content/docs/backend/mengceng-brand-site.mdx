# 梦层品牌官网与发布

梦层 MengCeng 面向独立创作者与小型创作团队，品牌域名为 MengCeng.com。域名解析、HTTPS 和上线状态以实际部署验收记录为准，部署合同见[梦层自建镜像部署](/docs/backend/mengceng-self-hosting)。`/` 始终显示官网；`/welcome` 重定向至 `/`。导航仅保留品牌与「开始创作」主操作，官网普通点击在当前页面打开认证弹窗；已登录在展示表单前继续目标入口。链接仍保留 `/login?next=…`，供直接访问、新窗口和其他应用入口使用。公开内容不等待会话读取，也不初始化工作区数据，不改变工作台本身的游客策略。

## 入口与页面切换

官网、认证及工作台共用应用路由，站内普通点击连续切换；外部链接、下载、第三方认证及新窗口保留原生语义。`BrandLink` 在独立预览无路由上下文时仍为普通链接，CMS 预览统一阻止导航。返回官网复用当前文档已成功读取的发布版，整页刷新后重新读取，不在当前页面热替换内容。

官网入口与直接认证地址共用 `BrandPublicLayout`：`/`、`/login`、`/register`、`/forgot-password`、`/i/:code` 都保留同一份真实 `WelcomePage`／`BrandSite` 发布内容；认证地址通过薄 `AuthScene` 适配同一个 `BrandAuthDialog`，不再保留第二套独立登录壳或复制背景。普通打开认证时地址更新为真实登录 URL，表单切换替换当前历史项并保留 next、其他查询、hash 和路由状态；刷新仍能打开对应表单。关闭后替换回 `/`，已有触发入口恢复焦点，直接打开的认证地址则回焦官网主入口；前进后退不重复弹出关闭的窗口。已登录访问 `/login` 继续安全 next，官网根地址仍显示品牌；邀请地址保留自己的成员提示与主动切换账号流程。身份未确认时只在浮层内等待，检查失败保留提示与可用表单。工作台会话与本地能力初始化仍在进入工作台后执行，不为认证背景加载工作区数据。

官网品牌链接和「返回官网」到 `/`；「创作台」「返回创作台」到 `/create`。画布编辑器的对应返回入口及功能关闭页与此一致。顶部、侧栏和分享页的登录入口保留当前路径、查询参数及 hash；登录、注册、找回密码和访问保护共用 `auth-navigation.ts` 的站内 next 校验与编码，拒绝站外地址、反斜线和控制字符。未携带有效 next 时继续 `/create`。工作区顶部与侧栏共用退出 hook：服务端退出成功后清理账号会话，再替换进入 `/login`；同步忽略重复命令，退出或清理失败不导航、不提示成功。退出后的登录地址显示相同官网背景与认证浮层。

## 设计与内容

官网采用石墨灰底、柔白文字与少量冷紫蓝操作强调色，表面通过明度区分层次；不再把模糊鲸鱼图片或彩色渐变铺到全页背景。影像保留在首屏、工作流及展示区域。导航只保留彩色 Logo、梦层中英文字标与「开始创作」，与首屏及后续内容共用左右边线；导航保留中性半透明表面，导航和首屏之间留出独立间距。配色只作用于品牌官网、认证弹窗及图库，不改工作台皮肤、主题偏好或认证服务。首屏影像铺到文字背后，高度随视口调整；默认素材保持比例自动放大覆盖容器，允许边缘裁切，不锁定素材画幅，也不采用左右分栏。

中文正文、导航和控件使用自托管 Source Han Sans CN 可变字体，品牌主标题、章节标题与收尾使用 Source Han Serif CN 450 字重；认证表单标题采用无衬线 550 字重，和字段保持清晰层级。两套字体均保留 250–900 连续字重，常用字优先子集共约 400 KiB，其余中文字形按 Unicode 区间加载；OFL 许可随素材保存。字体仅作用于品牌与认证场景，不改工作台字体。此前环绕小画框与银绿/朱红方案均已弃用。

官网顶部导航采用轻薄横栏：桌面高 64px、Logo 28px，手机高 60px、Logo 26px，圆角收为 12px、无厚重阴影；品牌链接与手机主按钮至少有 44px 高的点击区域。保留既有左右边线、品牌和唯一「开始创作」入口、键盘焦点及原地认证拦截，不增加导航菜单或改动首屏内容。

大屏使用独立的展示与阅读尺度：外层导航、首屏与章节共用流动边线，最大展示宽度 2560px，左右留白随容器变化；1600px 以上首屏高度在 580–920px 内随视口调整，标题最大 88px、文案区域限宽，缩略图带独立扩展到 560–760px。画廊最大宽 2000px，工作流最大宽 1760px，创作方法与流程的双栏内容最大宽 1520px，正文继续各自限行宽；不把导航、按钮和所有文字同比放大。小屏保留原有首屏比例与控件尺寸，后台窄屏预览按组件容器宽度响应。

内置标识按用户确认的彩色稿替换为两道错开的画框／门形构成的抽象 M，使用紫罗兰、蓝色到青色的渐变。`MengCengMark` 供官网、认证、工作台、后台及加载占位共用，各 SVG 实例使用独立渐变 ID；`public/logo.svg` 为同路径的透明矢量版本，初始及运行时内置 favicon 带版本参数。浅底组合字标位于 `public/brand/identity/mengceng-lockup-light.svg`，文字为字体轮廓，不依赖外部字体。已有文字的入口只替换符号，不重复叠加整套字标。运营自定义 Logo、深浅资源和框开关保持原合同；自定义图片失败仍留中性占位，不冒充内置品牌。

用户弃用首屏右侧嵌入式表单及独立二级登录壳，当前所有公开认证入口使用官网上方的居中认证弹窗。`BrandAuthProvider` 负责公开路由的预加载和入口导航，浮层统一由 `AuthScene` 挂载；预览、下载、外链、组合键及新窗口保留原合同。面板与输入框为不透明深色，首屏在遮罩后保留；登录、注册及找回密码复用真实表单，并在弹窗内切换，保留安全校验后的 next。固定面板最大宽 448px、高度为 600px 或视口减 32px，标题和选择栏保持位置，内容区域独立滚动；新模块准备好前保留当前表单，取消先淡出到透明的阶段，只对新表单使用 .82→1 的 160ms 局部反馈。快速反向选择使旧请求失效，最终表单与 URL 一致，加载失败可重试。键盘切换与减少动效直接更新；减少动效由本品牌弹窗的 AntD motion token 与 transition 配置禁用入退场，不用 CSS 强行取消动画而留下等待退场的组件。关闭时立即取消邀请校验与旧请求。普通注册关闭时，官网与直接 `/register` 统一使用邀请码入口；设置加载或失败时不猜测开放状态。`/i/:code` 直接验证原大小写代码，保留邀请状态、协议、验证、积分和成员切换合同，不再要求重复填写短码。

首屏影像带支持横向拖曳、点选、方向键/Home/End、自动轮换及暂停，选中缩略图通过影像带局部滚动保持可见，并显示当前片段进度。图片每 8 秒、视频每 10 秒轮换，静态图片缓慢运动，视频静音循环，切换交叉渐变。鼠标停留影像带、键盘操作或拖动时暂停，离开后延迟 1.2 秒继续；手动选片重新计时后继续轮换。显式暂停保持到用户主动播放，离屏和后台标签页暂停。自定义首屏图片/视频仍优先显示完整素材，不混入默认影像带。登录、注册、找回密码与邀请页使用同一石墨灰背景、实色面板及不透明输入框，延续官网弹窗的表面和控件层级；原生自动填充、密码显隐、错误状态、短屏滚动、next 与邀请合同保留。

「每一种想象，都有画面」包含八类工作流：视觉特效、时尚影像、商业广告、产品摄影、概念设计、品牌视觉、动态影像、建筑空间。分类位于带边框的分段选择器，鼠标停留 120ms 后切换，触屏与键盘仍可点选；选中底板滑动，场景使用区域内的 280ms 淡入，不调用整页 View Transition，也不捕获首屏影像或缩略图。快速连续选择以最后一次选择为准；减少动效时直接切换。动态影像对应标识参考、三维材质与标识动画，不使用人物行走流程。

工作流画布支持从整个节点主体拖动、背景平移、缩放与复位；连线跟随节点，节点坐标不限制在初始布局范围。桌面视口随屏高扩展，手机保留镜头选择以定位节点。聚焦节点标题后可用方向键移动、Shift 加速、Home 恢复；普通滚轮继续滚动页面，Ctrl / Command 加滚轮缩放。真实创作画布的代码、数据和行为不在本轮修改范围。

examples 内先显示 CMS 作品画廊，再显示八类可交互工作流，让访客先看成果，再了解创作方式；两者按真实 DOM 顺序渲染，视觉、键盘与辅助阅读顺序一致。画廊查看器支持上一张/下一张、方向键、Escape 关闭回焦。用户要求删除「从第一句，到最后一镜」后，公开页与预览均不再渲染 entries；存储字段及已保存数据不自动删除或发布。examples/process/faq 的已保存相对顺序、显隐、自定义媒体与最多 12 项合同保留，process 与 faq 默认隐藏；固定展示不替后台重排这些区块，也不丢弃自定义内容。

「灵感之外，还有方法」固定紧跟 examples 的画廊与工作流，后续再继续后台排序中的其他区块与收尾；仅在 examples 可见时出现一次。若管理员刻意将 FAQ 排在 examples 前面，该已保存相对顺序仍被尊重，不由固定方法区强制覆盖。四项内容对应现有预设目录中的短剧立项与大纲、广告全链路、AI 角色表演、电商大图与系列图；官网只展示方法简介、步骤和视觉案例，不自动安装技能、创建画布或运行模型。方法标题与预设 ID 由专项校验与内置目录保持一致；「探索技能库」通过 `/login?next=%2Fskills` 进入现有技能广场。官网不为这组展示发起技能列表、用户数据或生成请求。

桌面为大影像与右侧方法选择，手机依次显示介绍、画面和方法列表。鼠标停留 120ms 后切换，键盘聚焦和点选立即切换；影像交叉淡入，当前方法展示对应步骤。视频仅在当前项进入视口时加载，换项卸载旧视频；离屏、后台标签页、减少动效及管理员预览限制与官网其他动态展示一致，访客可以主动播放或暂停。此区随 examples 显隐，不新增 CMS 字段或覆盖已发布值。

五张原创图片位于 web/public/brand/b/，与既有 v5 素材并用。工作流及部分首屏视频按用户明确要求复用 FLORA 公开媒体，来源记录保留在源码与本机素材清单中；页面不展示来源说明、示意标签或开发备注，也不宣称这些片段是梦层收费模型实测成果。远程媒体不可用时保留封面图。视频只有当前场景进入视口后加载和播放，切换后暂停并卸载旧场景；预览不加载远程视频。减少动效偏好停用自动换片、镜头移动和动画过渡，访客仍可主动播放。没有新增后端接口、数据表或自动内容迁移。

官网认证弹窗每次打开时读取真实公开注册设置。公开注册关闭时，「注册」入口改为「内测用户邀请」，展示简洁的 6 位邀请码输入；开启时继续加载既有普通注册表单。设置读取中或失败时不猜测开放状态，可重试读取，已有账号仍可登录。邀请输入复用 `registration-invitations.ts` 的 `validateRegistrationInvitation(code, signal)` 和 `invitationPath(code)`：验证有效才进入 `/i/:code`，完整邀请链接由邀请模块直接处理，不重复输入。验证中、无效、过期、撤销、已用、网络/服务失败与限流分别反馈，网络失败保留重试，不当作邀请失效。品牌入口不计算积分、不消费邀请、不修改全局开关或 CMS 内容；邀请注册与积分到账由专用邀请模块负责。

## 后台与公开配置

管理员入口 `/admin/settings/brand-site`。编辑即时预览共用真实 `BrandSite` 渲染组件，支持桌面与 390px 手机预览；预览不会导航离开编辑页。全局名称/Logo、SEO 和工作台皮肤继续由「站点及外观」管理，官网编辑不会保存或覆盖这些草稿。认证页与官网共享品牌局部色值和实色操作，固定品牌场景与工作台明暗偏好分别处理；保留 autocomplete、密码显隐、错误/焦点/禁用反馈和短屏滚动。后台公共外壳保留现有中性基础、菜单、32px 管理密度和语义状态，本轮不随官网改色。旧登录宣传文案和视频配置继续退场，旧欢迎开关不改变官网根入口。

- `GET /api/public/brand-site`：仅返回 `content` 当前发布版，`Cache-Control: no-store`，不返回草稿或上一版。
- `GET /api/admin/settings/brand-site`：管理员读取草稿、发布版、上一版、修订号与时间。
- `POST /api/admin/settings/brand-site/draft`：`{ revision, content }`，验证后仅保存草稿。
- `POST /api/admin/settings/brand-site/publish`：`{ revision }`，再次校验草稿和媒体后，整版原子替换当前发布版，原发布版成为上一版。
- `POST /api/admin/settings/brand-site/restore`：`{ revision }`，交换当前与上一完整发布版，编辑草稿保持不变。

所有写操作由服务端 `RequireAdmin` 检查；请求体上限 128 KiB。前端显示未保存、已保存未发布、已发布及失败状态；失败不污染已发布版。请求修订号过时返回 409，重新载入前提示丢弃未保存内容。多实例通过数据库的 `key + 原始 value_json` 比较更新，不依赖进程锁保证原子性。

## 存储与媒体隔离

复用 `system_settings`，新增逻辑 key `brand_site`，不新增表、不修改 schema 版本。`value_json` 包含 `revision`、`draft`、`published`、`previous`、`draftSavedAt`、`publishedAt`；同一记录写入完整版本。首次无记录时使用内置梦层内容。该记录同样属于数据库备份范围。

媒体复用外观上传入口的 `brand-image` / `brand-video` 类型：校验文件类型与大小，固定私有本地资源，不使用可能公开的用户 OSS/CDN。图片最多 10 MiB、视频最多 256 MiB。上传不等于发布。配置校验检查归属、就绪状态、MIME、Kind、说明、封面和文件可读性。

`/api/admin/settings/brand-site/media/:id` 需管理员且拥有该资源，或资源已被官网版本引用。`/api/public/brand-site/media/:id` 只服务当前发布版引用，匿名猜测草稿/上一版 ID 不可访问。均不缓存；草稿、当前与上一版引用均接入资源删除保护，避免清理破坏恢复能力。上传后未保存的孤立资源仍按既有资源回收规则处理。

## 品牌迁移与边界

外观 JSON 合同版本 13 在读取旧配置时仅映射精确匹配的旧内置品牌名、slug、SEO、版权和助手名；读取不直接改写数据库，管理员正常保存时才持久化版本 13。不覆盖自定义运营文案、上传 Logo、皮肤或历史用户内容。旧 `authHero*` / `authVideo*` 字段不再进入管理员和公开类型、归一化及保存投影，旧登录视频/海报上传类型与公开 slot 已删除；未知旧 JSON 字段在下次正常保存时不再序列化，不为退场页面保留恢复开关，也不自动删除已上传文件。认证页与前台共享中性基础及明暗偏好，不加载官网影片；48px 输入框保留原生 autocomplete、错误/禁用状态与可见焦点。内置 Logo、favicon、认证邮件默认品牌、106 份内置技能的中文产品指代及可安全品牌化文案使用梦层；技能 ID 与第三方许可保持。

技术模块 `yingce`、容器/协议/存储 key、上游仓库链接和 LICENSE 保留；第三方素材许可页保留用于现有灵感素材的归属说明，不作为官网展示案例。发布后新打开或刷新取得新内容；已打开官网保持当前内容，不在媒体播放中突然热替换。真实付费生成、多人跨账号协作与一键自动成片均不作为本次承诺。
