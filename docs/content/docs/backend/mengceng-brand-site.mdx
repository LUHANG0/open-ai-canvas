# 梦层品牌官网与发布

梦层 MengCeng 面向独立创作者与小型创作团队，品牌域名为 MengCeng.com。域名解析、HTTPS 和上线状态以实际部署验收记录为准，部署合同见[梦层自建镜像部署](/docs/backend/mengceng-self-hosting)。`/` 始终显示官网；`/welcome` 重定向至 `/`。导航提供英文字标、产品功能菜单、章节入口与「开始创作」主操作，官网普通点击在当前页面打开认证弹窗；读取到已登录会话后继续安全目标入口。新入口统一显示 `/login`，站内普通点击通过当前认证历史条目的路由状态保存安全返回目标；复制纯登录链接或新窗口访问默认进入 `/create`。公开内容不等待会话读取，也不初始化工作区数据，不改变工作台本身的游客策略。

## 入口与页面切换

官网、认证及工作台共用应用路由，站内普通点击连续切换；外部链接、下载、第三方认证及新窗口保留原生语义。`BrandLink` 在独立预览无路由上下文时仍为普通链接，CMS 预览统一阻止导航。返回官网复用当前文档已成功读取的发布版，整页刷新后重新读取，不在当前页面热替换内容。

官网入口与直接认证地址共用 `BrandPublicLayout`：`/`、`/login`、`/register`、`/forgot-password`、`/i/:code` 都保留同一份真实 `WelcomePage`／`BrandSite` 发布内容；认证地址通过薄 `AuthScene` 适配同一个 `BrandAuthDialog`，不再保留第二套独立登录壳或复制背景。普通打开认证时地址更新为干净的认证路径，表单切换替换当前历史项并保留内部返回目标、必要的其他查询、hash 和路由状态；当前标签刷新仍能打开对应表单并恢复目标。关闭后替换回 `/`，已有触发入口恢复焦点，直接打开的认证地址则回焦官网主入口；前进后退不重复弹出关闭的窗口。已登录访问 `/login` 继续安全目标，官网根地址仍显示品牌；邀请地址保留自己的成员提示与主动切换账号流程。点击后立即打开浮层，表单模块、会话及注册政策并行读取；会话未确认不阻止账号密码填写，检查失败保留提示与可用表单。工作台会话与本地能力初始化仍在进入工作台后执行，不为认证背景加载工作区数据。

官网品牌链接和「返回官网」到 `/`；「创作台」「返回创作台」到 `/create`。画布编辑器的对应返回入口及功能关闭页与此一致。顶部、侧栏和分享页的登录入口保留当前路径、查询参数及 hash；登录、注册、找回密码和访问保护共用 `auth-navigation.ts` 的站内目标校验，拒绝站外地址、反斜线、控制字符和规范化后的认证自循环。没有有效内部目标时继续 `/create`。工作区顶部与侧栏共用退出 hook：服务端退出成功后清理账号会话，再替换进入 `/login`；同步忽略重复命令，退出或清理失败不导航、不提示成功。退出后的登录地址显示相同官网背景与认证浮层。

认证目标保存在当前历史条目的 `state.authReturn`，标签页 `sessionStorage` 仅保存流程标记，不保存目标，也不使用全局 `localStorage`。标记只在实际进入认证后建立，预加载、悬浮和组件 render 不写入；取消、完成认证、主动退出及离开认证后作废，后退／前进到已作废的旧条目使用默认目标。普通 SPA 离开与完整页面返回共用清理规则；浏览器缓存文档恢复时重新核对标记。存储不可写时使用当前文档内存降级，刷新后安全使用默认目标，不承诺受限存储下仍恢复具体去向。已有书签／外部 `?next=` 入口会安全校验后一次性迁入状态并 replace 清除该参数，目标自身的查询和 hash 保留；OAuth 错误、邀请码及其他业务参数不批量清理。Linux.do 后端 `/auth/linuxdo/start?next=…` 和 acceptedTerms／state／CSRF 合同保持原样。

## 设计与内容

官网采用深色影像版式。首屏为影像背景、中文标题、创意输入与创作入口；英文字标位于导航。桌面产品菜单支持鼠标悬浮和键盘展开，手机使用独立菜单。社媒影片集合紧跟首屏，随后展示视频创作、创作工作台与 CMS 已发布区块。旧影片缩略图带和方法切换组件不再由当前首页挂载。

品牌与认证使用自托管 Glow Sans SC（未来荧黑）Regular、Medium、Bold 字体，WOFF2 按 Unicode 区间分片，许可位于 `web/public/brand/fonts/GlowSans-OFL.txt`。工作台保留自身字体与皮肤。初始 HTML 与 React 页面共用 `/loading-v1.css` 的加载动画，`AppLoading` 统一页面、工作区、认证表单和画布刷新占位，减少动效时保留静态状态提示。首屏等待可用媒体画面和字体，字体等待最多 1.5 秒、媒体等待最多 8 秒；媒体超时使用本地品牌画面，不等待整段视频下载。

首页默认展示媒体直接引用 Vidu 与 OiiOii 的公开媒体地址，来源记录保留在对应源码；这些不是梦层客户作品或模型实测结果。桌面影片卡片仅在鼠标悬浮当前项时请求预览，离开停止；触屏和管理员预览不自动请求悬浮视频。点击打开带标题、关闭与播放控制的查看器；自动播放被浏览器拒绝时允许手动播放。离屏、后台标签与减少动效偏好控制默认背景播放。远程媒体的可用性依赖对应源站，加载失败保留可用封面或错误提示。

CMS 的 `entries` 显示产品入口，内置内容为「AI 视频创作、创作画布、短剧项目」。没有自定义媒体时，`BrandProductPreview` 结合本地原创画面绘制文字与参考生成镜头、连接素材的画布、角色与章节分镜等效果示意，不截取真实账号界面，也不读取用户项目。旧内置标题仅作精确匹配替换；管理员自定义标题、描述、链接和媒体继续保留。入口分别接入 `/create?mode=video`、`/canvas`、`/projects`，经安全认证返回目标进入对应功能。

产品入口 `entries` 后紧接八类可交互画布展示：视觉特效、时尚影像、商业广告、产品摄影、概念设计、品牌视觉、动态影像和建筑空间；隐藏 entries 时一起隐藏，其他 CMS 区块顺序不变。复用已有 FLORA 演示素材与节点几何，类型默认每 10 秒自动切到下一类，八类循环；鼠标悬停、按住指针操作或键盘焦点在展示内时暂停，离开后重新计时，手动选择（包含当前类）也重置计时。分类底部进度线与状态文字提示轮播状态；暂停按钮同时停止动态预览和自动切换。类型仍可鼠标停留、点击或方向键切换。节点支持拖动、键盘移动、Home 复位、缩放与整体重置；手机可用节点选择定位，空白处竖向手势与普通滚轮仍滚动页面。离屏、后台标签、减少动效和 CMS 预览停止自动轮播；减少动效时主动播放仅影响视频，不启用自动换类；「打开创作画布」通过现有认证返回 `/canvas`，演示不会创建用户数据或调用模型。

`examples` 保留图片放大、前后切换、键盘与关闭回焦；自定义视频显示原生控制。`process` 保留 CMS 步骤与故事内容。`faq` 使用两栏介绍与手风琴问题列表，手机纵向排列。四个 CMS 区块的已保存顺序、显隐及最多 12 项合同保持不变。页脚显示产品入口、版权与运营配置的备案信息，不显示旧的「下一幕，由你开始」收尾区。

首屏创意输入按有界纯文本交给认证返回目标，工作台完成账号与历史恢复后只处理一次；已有草稿或正在生成时保留当前创作，不直接提交模型任务。进入图片、视频或灵感大厅也通过同一入口逻辑处理，失败与取消不会覆盖已写内容。

## 认证与邀请

官网与直接认证地址共享 `BrandAuthDialog`，宽屏提供左侧影像与右侧表单，窄屏只保留可滚动表单。`BrandAuthProvider` 立即导航打开登录，不等待登录模块预加载。模块加载失败显示重新加载与刷新页面入口；旧表单切换期间保留内容，快速切换以最后请求为准。关闭使未完成请求失效，保留 Escape、焦点循环、回焦和减少动效支持。会话检查与表单加载并行，迟到的会话结果不会重置输入；已登录访问登录页则继续安全目标。

每次打开读取真实注册设置：公开注册关闭时显示「内测用户邀请」和 6 位邀请码入口，开启时使用普通注册表单；读取中或失败不猜测政策。`/i/:code` 直接验证原大小写代码，不重复要求短码。无效、过期、撤销、已使用及网络失败分别处理；验证码、协议、邀请消费和积分仍由服务端执行。

普通登录保留账号密码、可用的验证码方式和第三方登录；错误就近显示，设置读取失败时账号密码仍可操作。有效邀请在验证渠道未配置时允许填写基本资料，但不绕过验证码提交；可重新检查配置并保留已填信息。完整注册合同见[注册邀请](/docs/backend/registration-invitations)。

## 后台与公开配置

管理员入口 `/admin/settings/brand-site`。编辑即时预览共用真实 `BrandSite` 渲染组件，支持桌面与 390px 手机预览；预览不会导航离开编辑页。全局名称/Logo、SEO 和工作台皮肤继续由「站点及外观」管理，官网编辑不会保存或覆盖这些草稿。认证页与官网共享品牌局部色值和实色操作，固定品牌场景与工作台明暗偏好分别处理；保留 autocomplete、密码显隐、错误/焦点/禁用反馈和短屏滚动。后台公共外壳保留现有中性基础、菜单、32px 管理密度和语义状态，本轮不随官网改色。旧登录宣传文案和视频配置继续退场，旧欢迎开关不改变官网根入口。

- `GET /api/public/brand-site`：仅返回 `content` 当前发布版，`Cache-Control: no-store`，不返回草稿或上一版。
- `GET /api/admin/settings/brand-site`：管理员读取草稿、发布版、上一版、修订号与时间。
- `POST /api/admin/settings/brand-site/draft`：`{ revision, content }`，验证后仅保存草稿。
- `POST /api/admin/settings/brand-site/publish`：`{ revision }`，再次校验草稿和媒体后，整版原子替换当前发布版，原发布版成为上一版。
- `POST /api/admin/settings/brand-site/restore`：`{ revision }`，交换当前与上一完整发布版，编辑草稿保持不变。

所有写操作由服务端 `RequireAdmin` 检查；请求体上限 128 KiB。前端显示未保存、已保存未发布、已发布及失败状态；失败不污染已发布版。请求修订号过时返回 409，重新载入前提示丢弃未保存内容。多实例通过数据库的 `key + 原始 value_json` 比较更新，不依赖进程锁保证原子性。

## 存储与媒体隔离

复用 `system_settings`，新增逻辑 key `brand_site`，不新增表、不修改 schema 版本。`value_json` 包含 `revision`、`draft`、`published`、`previous`、`draftSavedAt`、`publishedAt`；同一记录写入完整版本。首次无记录时使用内置梦层内容。该记录同样属于数据库备份范围。

服务端默认内容用于尚未保存配置的新安装；前端默认内容用于公开读取失败时的回退，两者不代表当前已发布内容。更新内置内容不会改写现有 `brand_site` 的草稿、发布版或上一版；运营修改标题、详情或 FAQ 后，必须先保存草稿、在真实预览中核对，再手动发布，公开页才会取得新内容。

媒体复用外观上传入口的 `brand-image` / `brand-video` 类型：校验文件类型与大小，固定私有本地资源，不使用可能公开的用户 OSS/CDN。图片最多 10 MiB、视频最多 256 MiB。上传不等于发布。配置校验检查归属、就绪状态、MIME、Kind、说明、封面和文件可读性。

`/api/admin/settings/brand-site/media/:id` 需管理员且拥有该资源，或资源已被官网版本引用。`/api/public/brand-site/media/:id` 只服务当前发布版引用，匿名猜测草稿/上一版 ID 不可访问。均不缓存；草稿、当前与上一版引用均接入资源删除保护，避免清理破坏恢复能力。上传后未保存的孤立资源仍按既有资源回收规则处理。

## 品牌迁移与边界

外观 JSON 合同版本 13 在读取旧配置时仅映射精确匹配的旧内置品牌名、slug、SEO、版权和助手名；读取不直接改写数据库，管理员正常保存时才持久化版本 13。不覆盖自定义运营文案、上传 Logo、皮肤或历史用户内容。旧 `authHero*` / `authVideo*` 字段不再进入管理员和公开类型、归一化及保存投影，旧登录视频/海报上传类型与公开 slot 已删除；未知旧 JSON 字段在下次正常保存时不再序列化，不为退场页面保留恢复开关，也不自动删除已上传文件。认证页使用品牌深色表面与适配窄屏的表单，保留原生 autocomplete、错误/禁用状态与可见焦点。内置 Logo、favicon、认证邮件默认品牌、106 份内置技能的中文产品指代及可安全品牌化文案使用梦层；技能 ID 与第三方许可保持。

技术模块 `yingce`、容器/协议/存储 key、上游仓库链接和 LICENSE 保留；第三方素材许可页保留用于现有灵感素材的归属说明，不作为官网展示案例。发布后新打开或刷新取得新内容；已打开官网保持当前内容，不在媒体播放中突然热替换。真实付费生成、多人跨账号协作与一键自动成片均不作为本次承诺。
