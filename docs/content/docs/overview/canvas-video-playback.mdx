# 画布视频播放与选择

2026-10-31 根据用户指定的 LibTV 实际画布交互调整。视频采用临时播放器，与节点选择衔接；取消选择后收起，重新进入从头播放。此前设计的跨节点暂停帧、历史进度和“已暂停 N 秒”徽标已移除。

## 播放交互

- 鼠标悬浮 350ms 后有声预览；触摸、减少动态效果偏好和画布交互期间不触发。缩放/平移暂停悬浮后，在交互停止时重新判断鼠标是否仍命中当前视频，符合条件就重新计时，无需先移出再移入。悬浮离开释放播放器，下次从零开始。
- 点击视频画面会同时选择节点、显示其工具，并转入正式播放。悬浮转正式播放沿用同一播放器和当前位置。点击画面本身不切换播放/暂停；该操作由底部控件承担。
- 默认封面不显示常驻中央播放圆钮，保留键盘可聚焦的播放入口。播放中使用同一套精简控件；浏览器拦截和错误时才显示显式重试入口。
- 普通主键单击画布空白取消选择并收起播放器；选择另一个节点也会收起原正式播放器。重新进入原视频从零开始，不保存历史暂停帧或进度。
- 底部暂停控件保留当前播放器和画面，再次播放继续当前进度。悬浮播放器上的控件操作会转入节点选择，避免暂停动作被下一次悬浮覆盖。
- 正式播放的播放意图（包括加载和缓冲）阻止其他视频悬浮抢占。手动暂停、结束或失败后，仍保护当前节点不被自身悬浮重新启动，但允许其他视频悬浮预览。外部音频或弹窗释放所有权后，也会重新检查等待中的悬浮。点击另一段视频或音频会切换媒体所有权，包括脱离 DOM 的节点音频。
- 正式播放结束回到零并等待重新播放；悬浮播放结束释放播放器。
- 实际播放时鼠标静止 1.2 秒隐藏，移动或暂停恢复。窗口失焦或页面进入后台暂停；等待中的悬浮会取消。切到资产视图关闭画布播放器，返回不自动恢复。
- Esc 优先交给浮层、输入框、播放器控件与全屏；无这些交互时收起画布播放器。
- 默认优先有声播放；刷新后若 Chrome 拒绝有声自动播放，当前悬浮会话只回退一次静音预览，显示“静音预览 · 开启声音”。点击该入口或视频画面转正式播放时解除这次临时静音，沿用同一播放器和进度。临时回退不写入声音偏好。当前画布内用户选择的静音与音量跨节点、音频、资产详情及视频弹窗沿用。确认无音轨的源不会覆盖用户的声音偏好。

空白单击在指针抬起后确认，移动超过 3px、取消、修饰键、空格平移和多指操作不触发收起。节点、连线和 `data-canvas-no-zoom`/浮层区域不属于空白。视频画面播放通过既有节点选择手势的单击确认触发，区分拖动、修饰键及播放器控件，不依赖可能因节点置顶移动而丢失的原生 click，也不把拖动结束当成播放请求。

## 框选交互

- 与参考实测一致，两个方向均使用相交命中：选框接触节点一部分即可选中，不再使用“从左到右必须全包，从右到左只需相交”的差异规则。
- 拖动中的选框使用实线和轻填色；命中节点出现与最终选择相同的描边。松手后，每个选中节点仍有独立描边，多选集合保留外围虚线框与数量工具栏。
- 描边使用画布主题自身的颜色：浅色为深色，深色为浅色，不依赖工作台强调色；宽度和间距随实时缩放反向补偿，保持约 1.5px 屏幕宽度。
- Shift 添加、平台修饰键切换、Alt 移除及取消手势恢复初始选择的现有合同保留。触摸、空格和中键平移继续走导航路径。
- 移动期间只更新命中差量的 DOM 标记和图形层，指针抬起后一次提交最终选择集合；不逐帧重渲染全部节点。

## 状态与资源边界

`CanvasPlaybackController` 仅保留当前播放器的身份、模式、意图、实际状态、当前恢复位置和画布声音偏好。没有跨节点播放书签和暂停帧缓存，也不保存签名 URL、写画布快照、数据库或浏览器持久化。删除、账号/画布作用域变化和离开视口均清理对应所有者。过期播放器回调按 token 丢弃。

播放控制器由画布页面按账号/项目作用域持有，选择手势和播放器共用同一实例。播放器存续期间保留已挂载节点的 DOM 相对顺序，选中置顶仍由现有 z-index 实现，待会话关闭后再应用排序，避免移动 Vidstack 自定义元素导致原生视频被重建。悬浮等待监听指针移动、视口交互结束、可见性及媒体所有权变化，启动前检查真实命中；被遮挡或已移开的节点不会启动。有声被阻止后最多追加一次静音尝试，静音仍失败则停止；错误及自然结束不会形成自动重试/循环播放。

封面组件在静态、悬浮和正式播放之间保持挂载，复用已经解码的图片；播放器在首帧实际呈现后直接覆盖不透明封面，不同时淡出封面与淡入视频，避免重新解析封面的空档和黑底透出。退出播放恢复同一封面；媒体身份变化才替换封面。已完成的视频在普通、概览和外部预加载层级间也复用该封面，不因缩放切换预览组件；普通媒体节点的阴影在缩放交互和概览之间保持一致。生成中、错误、自定义预演和批量节点保留原有渲染路径。尺寸、源文件、任务、账号和节点身份校验继续走已有合同。地址解析由 `useVideoPlaybackUrl` 与 `resolveVideoMediaUrl` 承担，续签不把 URL 变成 React key。资源恢复前同步读取当前位置；同一会话恢复可继续，期间暂停不能被完成回调覆盖，已经取消选择的旧请求也不能重新开播。

首帧捕获不再固定缩为 400px：保留原始尺寸，长边上限 1920px，JPEG 质量 0.94，不放大小视频。已知原视频尺寸且已有生成封面尺寸不足时，仅在附近视口内按原有空闲/串行抽帧路径升级；自定义封面和未知尺寸不盲目覆盖。封面写入仍检查账号、媒体、任务和并发封面身份。高清封面解析/解码期间保留旧图，成功后原位替换，失败继续显示旧图；切号或换媒体立即隔离旧图。原视频文件不修改。

加载、恢复、缓冲、跳转、正在播放、暂停、结束、浏览器拦截和错误分别记录；只有 `playing` 事件确认实际播放。正式播放被拦截，或悬浮的静音回退也被拦截时，显示“点击播放以启用声音”并保留按钮。网络/解码失败不按自动播放策略降级。悬浮加载/缓冲停滞超过 8 秒进入可重试错误状态。

## 实现与验证入口

- `web/src/lib/canvas/canvas-playback.ts`：当前会话、收起/暂停、进度、过期事件和空白点击判据。
- `web/src/components/canvas/canvas-playback-context.tsx`：作用域、节点激活与页面生命周期。
- `web/src/pages/canvas/project.tsx`、`use-canvas-selection-controller.ts`：选择手势确认与播放激活。
- `web/src/pages/canvas/canvas-project-world-layers.tsx`：选择/节点删除清理与播放期间稳定 DOM 顺序。
- `web/src/components/canvas/canvas-node.tsx`：节点控件、选中标记与描边语义。
- `web/src/lib/canvas/canvas-video-hover.ts`：悬浮等待、视口恢复、命中校验及一次停留的重试边界。
- `web/src/components/canvas/canvas-node-media-content.tsx`、`use-canvas-video-playback.ts`：单一播放表面、悬浮、首帧、恢复位置与鼠标。
- `web/src/lib/canvas/media-playback-focus.ts`：节点、弹窗、原生预览与节点音频之间的播放所有权。
- `web/src/lib/canvas/canvas-selection.ts`、`use-canvas-selection-controller.ts`：命中、修饰键、手势与最终提交。
- `web/src/components/canvas/canvas-leafer-graphics-layer.tsx`、`web/src/styles/globals.css`：选框、集合外框及节点命中/选中描边。

自动化验证区分控制器、真实组件衔接、资源替身、选择算法和输入手势；真实验收使用 Google Chrome 的实际画布及浅深主题。LibTV 的生成、计费、素材修改等功能不属于复刻范围；测试通过不代表线上、手机真机或所有参考场景已验收。
