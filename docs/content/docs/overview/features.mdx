# 功能清单

## 用户邀请注册

管理员可在 `/admin/users` 使用主操作“邀请注册”创建单次链接，可选 1 天、3 天或 7 天有效期，并选择 50、100 或自定义整数积分。链接只在创建成功时显示一次；记录页展示固定注册积分以及待使用、已使用、已过期和已撤销状态。

有效邀请不会开启全局公开注册，但在公开注册关闭时仍能创建一名普通用户。受邀注册的邮箱可选且不要求邮件验证码；用户名、密码、唯一性、限流和自动登录仍沿用常规合同。注册成功后，邀请上固定的积分在同一事务中自动到账，覆盖普通注册奖励，无需另发积分兑换码。地址栏 token 在成功交换为短期 HttpOnly Cookie 后立即移除。

## AI 提示词优化器

提示词优化器是一个内置 AI 能力插件，用于把模糊的生图或生视频想法整理成可以直接使用的提示词。它复用宿主已经配置的文本模型和渠道，不在浏览器中保存或拼接第三方密钥。

### 使用入口

- 创作页 `/create` 的提示词输入框中，点击“优化”。
- 画布中的图片或视频节点提示词编辑器中，点击“优化”。

面板使用紧凑的聊天式交互，跟随当前输入框定位，支持拖动、边缘调整尺寸和窗口尺寸变化。打开与关闭不使用延迟动效，避免遮挡画布或让用户误以为请求卡住。

### 优化方式

| 方式 | 用途 |
| --- | --- |
| 扩展想法 | 从模糊想法补齐主体、场景、构图、光线、镜头等可执行细节。 |
| 精修已有提示词 | 尽量保留原意，只修正表达并补充必要细节。 |
| 强化风格 | 保留主体和动作，强化色彩、材质、光影与指定风格。 |
| 适配模型 | 按当前生成模型和协议调整提示词结构，避免使用未确认的参数语法。 |
| 结合参考 | 使用已连接的图片或文本补充外观、一致性、构图和关联关系。 |

面板底部可以单独选择优化所使用的文本模型；目标生成模型仍取当前图片或视频生成配置。两者职责不同：前者负责整理提示词，后者负责最终生成内容。

### 结果与安全边界

- 优化结果以结构化内容返回，包含正向提示词、规避项、修改说明、假设和可选备选版本。
- 结果可以继续编辑；只有点击“采用”才会回填当前输入框，并自动关闭面板。
- 请求支持流式反馈、取消和错误提示，不会在优化失败时覆盖原提示词。
- 参考素材只提交当前已连接且符合类型的内容；插件不自行访问素材库或后端密钥。

### 相关实现

- `web/src/lib/plugins/builtin/prompt-optimizer.ts`：插件清单、优化方式和模型适配策略。
- `web/src/components/canvas/canvas-prompt-optimizer-drawer.tsx`：聊天面板、拖动缩放和结果采用交互。
- `web/src/services/plugin-host.ts`：将插件文本请求接入宿主现有模型渠道。
- `web/src/pages/create/index.tsx`、`web/src/components/canvas/canvas-node-prompt-panel.tsx`：两个入口的接入。

## 用户诊断包导出

设置页的“问题诊断”入口和任务失败快捷入口支持导出脱敏诊断包，帮助普通用户提交问题时保留足够的排障上下文。

### 当前能力

- 浏览器内存中保留最近的全局错误、未处理 Promise、API 请求和任务创建事件。
- 后端按当前登录用户、时间范围、任务或项目聚合 `Task`、`TaskLog` 和 `ApiCallLog`。
- 下载前显示数据量预览，并生成包含清单、运行时信息和 JSONL 日志的 ZIP。
- 默认排除提示词、任务输入、API Key、Cookie、上游请求/响应体和 URL 查询参数。

### 使用入口

- 设置页：`/settings?section=diagnostics`。
- 失败任务详情中的“导出诊断包”按钮会自动带入任务和项目范围。

相关设计和接口边界见[用户诊断包设计](../../../design/user-diagnostic-bundle.mdx)。

## 短剧本机交付包

短剧项目的“交付与打包”阶段支持把当前章节直接导出为 ZIP。只有当每个镜头都有已选中、可读取的视频时，导出按钮才可用。

交付包包含：

- 按镜头顺序合成的 MP4 成片。
- 按镜头时长生成的 SRT 台词字幕。
- JSON 和 CSV 分镜表，包含镜头参数、生成提示词和资源对应关系。
- 当前章节引用的资产版本清单、交付清单和说明文件。

镜头资源读取、视频合成与 ZIP 打包全部在当前浏览器完成，不会为打包额外上传素材。开始读取前会根据当前设备能力核对视频总容量，读取时还会按实际体积再次检查；超过本机安全上限时会在视频合成前停止，并提示拆分章节。旧版本的过期产物保留为历史记录；只要同一镜头已有新的选中视频，就不会阻断交付。

## 短剧缺失视频批量生成

短剧工作台的视频生成阶段会统计当前章节中缺少已选中视频、且没有排队或运行任务的镜头。点击“批量生成缺失视频”后，系统只使用各镜头已经保存的脚本版本，并按每个镜头的时长、图片与声音参考统一检查当前视频模型。

所有候选通过预检后才会展示费用确认。确认后，每个镜头仍建立独立后台任务，最多同时提交 3 个；单个镜头提交失败不会取消其他已经成功提交的任务。没有保存脚本版本、已经有可用视频或正在生成的镜头会自动跳过。

## 短剧 12 宫格动作预演

黑白动作预演统一输出一张 3 列 × 4 行的 12 宫格动作板。格子按时间从左到右、从上到下排列，保持角色、服装、场景、道具、光线和视线方向连续，用起势、推进、转折、落点和结束姿态检查动作节拍。

除当前镜头单独生成外，预演阶段还可以批量生成缺失动作板。系统只选择有已保存脚本版本、没有已选中预演、也没有排队或运行任务的镜头；逐镜头检查图片参考与模型兼容性，费用确认后最多并发提交 3 个独立后台任务。行数、列数和帧数会写入产物元数据，刷新后沿用原任务恢复链路。

## 章节资产拆分

章节编辑器可以把已保存正文交给文本模型，统一识别后续制作需要跨镜头保持一致的角色、场景、服饰、道具和武器。服务端使用固定 JSON 契约保护正文、项目画风和分类字段；结果不直接写成正式资产，而是进入“角色与资产”的待确认区。

候选会按分类和名称/别名去重，刷新页面后仍能恢复已经完成的拆分任务。角色候选保留完整角色卡与声音画像，其他资产保留制作描述、视觉约束、连续性要求和正文依据。用户可以在全部资产或对应分类中逐项确认；旧版角色提取任务仍可继续恢复。

## Eagle 外部素材库

内置 Eagle 插件可以从用户配置的 Eagle 服务读取素材、文件夹和标签，并将素材映射为工作台可引用的外部资源。

### 当前能力

- 支持按文件夹、关键词和素材类型查询 Eagle 素材。
- 素材没有文件夹或标签时，仍返回稳定的空集合，工作台可以继续展示和引用素材。
- 保留素材的文件夹路径、标签、扩展名、尺寸、大小和修改时间等排障与展示信息。

### 相关实现

- `backend/internal/service/eagle.go`：Eagle 响应解析和集合字段归一化。
- `web/src/lib/plugins/builtin/eagle.ts`：外部素材映射、预览和引用处理。

## 画布节点自动整理

画布底部的“自动整理节点”按钮用于快速改善节点排布，适合处理节点散落、间距不一致或流程方向不清晰的画布。

### 使用规则

- 选中了两个或以上节点时，只整理选中的可移动节点；没有选中节点时，整理所有顶层可移动节点。
- 候选节点存在连线时，按连线依赖关系进行流程布局；没有连线时，自动使用网格布局。
- 锁定节点、容器节点和折叠批次中的隐藏子节点不会被移动。
- 节点位置变化会进入现有画布历史记录，可使用“撤销”恢复整理前的布局，并继续由画布生命周期自动保存。

### 相关实现

- `web/src/components/canvas/canvas-zoom-controls.tsx`：底部视图控制 Dock 与“自动整理节点”入口。
- `web/src/pages/canvas/use-canvas-node-operations.ts`：候选节点筛选、流程/网格布局选择和位置提交。
- `web/src/lib/canvas/canvas-layout.ts`：流程、网格、行列排列和对齐算法。
