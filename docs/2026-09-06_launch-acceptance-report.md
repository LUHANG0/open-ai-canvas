# 2026-09-06 本地上线验收报告

本轮完成品牌改造后的跨模块隔离验收，并修复三处实际复现的问题：章节/分镜离开确认框的键盘焦点、同一任务连续重试重复请求、素材提示保存成功后立即刷新丢失记录。生产放量仍需完成本文的上线门禁；本报告不替代真实供应商、生产环境和用户观感验收。

## 范围与环境

- 起点为本地 `main` 的 `ab0d0a6d`，来自 `origin/main` 历史；未获取、推送或发布远端候选。D3 导演台/时间线由并行任务独立交接后再组合验证，最终提交见集成记录。
- macOS 15.7.8 / Apple M1 / Chrome headless，独立浏览器会话；前端 3013、隔离 Go 后端 8093，显式使用忽略目录中的 SQLite schema 8 数据库。开发环境 Go 为 1.26.5。
- SMTP、S3 和文本供应商均为仅监听本机的测试服务。使用虚构账号、凭据和微型自制媒体。仅为本地模型精确放行 localhost/127.0.0.1 并开启桌面本地渠道能力，未修改生产配置。
- 真实 8080 仅查询健康信息，未写入账号、积分、配置或内容；没有外部邮件、付费生成、推送、部署或生产恢复。
- 完整脚本、原始失败日志、截图、媒体和隔离数据保存在 Git 忽略的本地归档。仓库证据仅保留脱敏摘要和可复核检查，不提交登录态、密钥或数据库。
