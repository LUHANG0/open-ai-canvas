梦层已发布的 Schema 60/61/62 分别为创作对话历史、注册邀请和任务提交回执；上游同号记录分别为用户反馈、短剧制作和短剧片段。因此不能使用官方迁移表替换梦层迁移表，也不能将版本常量直接改为 87。
