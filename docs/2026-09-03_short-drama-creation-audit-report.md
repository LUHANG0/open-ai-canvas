# 短剧创作全链路审计与优化报告

> 审计基线：`a855fa6`。独立分支：`refactor/short-drama-creation-audit-20260903`。基线标签：`audit/short-drama-creation-base-a855fa6`。
>
> 所有结论以当前分支代码、测试或运行验证为依据；不包含付费生成、真实计费配置修改或用户数据删除。

## 当前结论

短剧项目已经具备“项目 → 章节 → 角色与资产 → 分镜脚本 → 图片/动作预演/视频 → 交付与画布”的主体链路。本轮已修复审计中发现的数据丢失风险、跨章节错误恢复、生成前副作用、阶段提示语错配、失败步骤不可重试和部分成功不可达等问题；列表、空态、错误态和 PC 主路径也完成了非破坏性浏览器回归。在此基础上，继续完成了分镜制作工作台、章节编辑页和项目入口页的职责拆分，并在拆分后复核中修正了等值轮询重载镜头编辑器、项目创建投影模块越权写入和画幅下拉误改内容来源状态三个边界问题。页面保留流程编排，新模块只承接展示、纯状态投影与草稿生命周期，接口、后端协议和用户路径保持不变。仍未接入的是交付打包后端；真实模型生成与计费路径按约束保留为待用户确认项。

## 范围与边界

本轮实施覆盖 `web/src/pages/projects/`、项目 API 客户端、项目与画布衔接、相关前端测试，以及后端项目只读路径。后端、Admin、数据库、权限、计费和协议保持不变；只有发现阻断性正确性缺陷时才允许最小后端修复并单独记录。

不执行以下操作：

- 不触发真实图片、视频或文本付费生成。
- 不删除真实用户项目、章节、素材或产物。
- 不修改真实模型渠道、积分价格、权限或部署配置。
- 不对移动端做视觉重构，只验证 PC 样式没有泄漏到小屏规则。

## 代码治理续阶段

本次续阶段只调整前端代码边界，没有改变 API 调用、请求结构、后端协议、数据库、权限、计费或 Admin。三处原始页面继续作为流程协调器，避免为了追求文件行数而拆散跨步骤事务。

| 原协调器 | 拆分后规模 | 新模块职责 | 有意保留在协调器的职责 |

| `projects/index.tsx` | 663 行 | 项目卡片、AI 响应解析、重名候选和生成进度投影 | 重名创建重试，以及“生成并校验章节 → 创建项目 → 导入章节 → 失败后导航”的顺序 |

分镜草稿是本次唯一继续下沉的有状态生命周期：新 hook 仍以用户、项目、章节、镜头和服务端版本共同标识草稿；加载 effect 不跟随普通轮询结果反复执行，因而不会用服务端旧快照覆盖当前未保存编辑。其余跨请求流程保留在页面，优先维持用户可见行为和失败恢复语义。

- 每个职责拆分和复核提交前均通过 TypeScript 检查和对应专项测试；最终专项集合为 24 个文件、113 项测试全部通过。

## 复核结论与停止点

| Evidence | Finding | Path | 修复与门禁 |
| --- | --- | --- | --- |
| `useWorkflowShotDraft` 的装载 effect 直接依赖 `serverValues` 对象；工作区刷新会重新构造引用上下文和表单值，即使字段完全相同也会获得新对象 | 等值任务轮询可能再次执行 `form.setFieldsValue`，覆盖用户正在输入的镜头脚本 | 项目轮询刷新 → 新 `detail`/引用数组 → 新 `serverValues` 对象 → 草稿装载 effect → 表单重置 | `shotEditorValuesKey` 按固定字段顺序生成稳定快照；测试验证等值对象同键、字段变化异键，并锁定 hook 依赖快照键 |
| `project-story-generation.ts` 直接导入并调用 `createProject`；`aspectRatio` 表单项的 `onChange` 调用了 `setCreateSource` | 纯投影模块承担业务写入；用户修改画幅会把内容来源状态写成 `9:16/16:9/1:1`，造成按钮选中态和后续表单初始化错位 | 画幅下拉 → `setCreateSource(画幅)` → 非法来源状态；AI 解析模块 → 项目 API 写入 | API 重试回到页面协调器；投影模块只输出重名候选/冲突判断；内容来源下拉独立更新 `createSource`；源码交互门禁验证两个表单块不再串线 |

复核后达到合理停止点，依据如下：

- 所有新拆分的展示/投影模块均未直接发起项目、章节、镜头或生成任务写请求；资源 URL 解析仅用于展示。
- 镜头生成的“校验 → 技能准备 → 工作流初始化/恢复 → 保存镜头 → 提交任务 → 部分失败提示”和章节任务恢复仍完整保留在协调器，没有为降低行数而抽象事务。
- 章节编辑仅在章节 ID 变化时重新装载服务端正文；镜头编辑改用字段快照键；没有发现另一条由普通轮询对象身份触发的编辑覆盖路径。
- TypeScript、24 文件专项 113 项、PC/小屏预检 26 项和生产构建全部通过；构建仍为 13,634 个模块，仅有 chunk-size 提示。
- 后续可扩展项只剩交付打包、真实付费模型验收和既有导演模板测试锚点，均超出本次低风险前端治理边界。

| AI 创建项目 | 模型或 JSON 失败后可能留下空项目 | 先生成并校验，再创建和导入；导入失败则进入已创建项目并提示继续处理 |
| 资产与画布 | 请求失败像空数据；待确认角色默认不易发现；画布关联失败后停在原页 | 错误态和重试明确；默认全量视图可见候选；关联部分失败仍打开已创建画布 |
| 章节展示 | 制作流程可能直接显示 HTML 标签 | 统一转换为保留段落、换行和列表顺序的纯文本 |
